PPM timezone formula extensions embed immutable transition data derived from
IANA tzdb 2026f via Python tzdata 2026.6. UTC transition coverage for named zones
is 1970-01-01 through 2101-01-01 (exclusive). The source/version hashes and IANA,
Python tzdata and Apache notices are in licenses/timezones. No host timezone or
network lookup is used to execute these formula extensions.
