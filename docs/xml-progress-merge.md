# XML 작업 진척의 기존 문서 병합

2026-11-13 후속: [공수 기반 작업 기간 병합 XWP-01~06](xml-work-driven-progress.md)을 추가했다. 아래의 공수 작업 거절/잔여 표기는 명시 RemainingWork를 검토하는 새 지원 부분으로 대체한다. 기간 보고는 보존하고 native 예측은 현재 공수 계획에 따라 별도 계산한다.

후속: [배정·일별 실제 공수/원가 XAP-01~06](xml-period-actual-adoption.md)은 별도 흐름으로 제공한다. 아래 문서는 작업 날짜/기간 진척 병합의 계약과 당시 검증 범위다.

2026-11-12 · XPM-01~06. 파일 메뉴의 **XML 작업 진척을 현재 문서에 병합…**에서 현재 native 계획을 유지하고 선택한 작업의 보고를 추가한다. [새 사본 채택](xml-progress-adoption.md)과 별도 동작이다.

- **XPM-01 명시 연결·대사:** 모든 행은 미선택, 대상 작업은 미지정으로 시작한다. 원본 UID/작업명·대상 native ID/이름·현재 상태일의 보고·수신 실제 날짜/실제·잔여 분을 나란히 표시한다. 이름이나 순서로 연결을 추측하지 않는다. 선택하지 않은 행은 현재 보고를 유지한다. 선택한 UID 또는 대상 작업의 중복, 없는 작업과 불완전 후보를 거절한다.
- **XPM-02 상태일·지원 범위:** 기존 문서에 상태일을 먼저 지정해야 한다. XML 상태일과 현재 상태일을 구별해 표시하며 선택 확인은 **현재 상태일에 기록**하는 동의다. 문서 상태일을 자동 변경하지 않는다. ActualStart/Finish·명시 ActualDuration/RemainingDuration만 가져오며 새 사본과 같은 정밀도/날짜 일관성 검사를 사용한다. 공수로 계산하는 작업은 기간 진척 병합을 거절한다. 배정별/기간별 실제 공수·원가를 추정하지 않는다.
- **XPM-03 불변 원장·충돌:** 선택한 행은 해당 작업의 마지막 원장 보고를 `previousEntryId`로 잇는 정정 보고가 된다. 현재 상태일에서 선택되지 않는 미래 보고도 삭제하지 않는다. 여러 행은 native 문서 ID·한 revision으로 기록하고 기존 계획·원장 행을 변경하지 않는다. undo로 제출 사실을 제거하지 않고 후속 정정으로 처리한다. 원장에 이미 반영한 최신 보고 ID와 상태일을 재검사한다.
- **XPM-04 중복·재수입:** 원본 바이트 SHA-256·UID·채택 상태일로 중복을 식별한다. 동일 원본을 같은 대상에 재수입하면 새 행/revision을 만들지 않으며, 그 후의 native 정정을 되돌리지 않는다. 같은 출처 UID를 같은 상태일에 다른 작업으로 재연결하면 거절한다. native ID 이관 뒤에도 출처 표식과 이관된 작업 ID로 대조한다. 다른 원본 바이트나 다른 현재 상태일은 새 검토 대상으로 취급하므로 선택한 행만 명시 반영한다. 파일명만 바꾼 동일 바이트는 중복이다.
- **XPM-05 원자성·잠금:** 원본 XML을 다시 파싱해 후보/계획/해시를 대조한다. 격리된 worker에서 전체 batch·native 유효성·마감 기간을 검증한 뒤 세션/revision이 같은 문서에 한 번만 적용한다. 마지막 행의 오류·취소·검토 중 편집·읽기 전용·닫힌 재무기간은 부분 반영하지 않는다. 원본 XML과 현재 native 파일을 자동 덮어쓰지 않는다. 반영 후 일반 저장/자동 복구를 사용한다.
- **XPM-06 출처·보고·저장:** 각 추가 보고의 불변 사유에 SHA-256·UID·원본 파일명·사용자 사유를 기록하고 기존 reporter/UTC/상태일·native ID·이전 보고 연결을 보존한다. 감사 보고서는 기존 native 보고·XML 보고·후속 정정 전체를 포함한다. 기존 ProgressEntry 형식과 최소 writer를 재사용하며 지원 상한51은 유지한다. 테스트 fixture는 Actual 수식 때문에 schema48이다. 원본 XML 바이트와 XML 상태일의 재검증에는 사용자가 원본 파일을 함께 보관해야 한다. 이 흐름은 원본 바이트나 미선택 연결을 native 파일에 내장하지 않는다.
