## 지원 범위

MPXJ16.10.0이 실제로 읽은 `RawTimephasedRemainingRegularWork`를 사용한다. 실제공수가 없는 배정에서는 이 정규 잔여 분포를 계획 공수로 채택할 수 있다. 기본 곡선뿐 아니라 수동 배정률, 명시0/유휴 구간과 분할된 계획 분포를 읽는다. 없는 원본 데이터를 생성하지 않는다. 기간 기반 새 계획 사본을 만들고 현재 문서의 실적·기준선을 덮어쓰지 않는 기존 흐름을 유지한다.

- 실제공수/실제 초과근무 또는 해당 원본 시간대 자료가 있는 배정은 분포 채택에서 제외한다. 잔여 초과근무와 그 시간대 자료도 별도로 제외한다. 제외 수와 원본 자료가 없는 수동 곡선 수를 보고한다. 지원되는 기본 곡선 코드의 기존 정적 계획 해석은 유지하며, 실적을 전체 계획 곡선으로 재구성하지 않는다.
- 채택하는 시간대 자료는 Type1 정규 계획 공수만 출력한다. 실제공수·초과근무·기준선·원가 시간대 자료를 native 관측 원장으로 만들지 않는다. MSPDIWriter가 실적 비율만 있는 미배정 작업에 만들려는 가짜 배정도 억제하고 수를 기록한다. 원본 바이너리는 그대로 보존한다.
- 요약 작업의 직접 배정, 수동 일정 모드, 비균일 요일/일회성 추가 근무·부분일 예외 등 기존 달력/작업 제한은 유지한다. 지원하지 않는 조합은 전체 변환을 거절한다. 정상 전일 휴일의 종료 표기 `23:59:59`는 동일 날짜의 휴일로 받아들인다.

## 분 단위 투영

native 날짜 축은 정수 분이고 공수는1/100자원분이다. 시간대 경계는 다음 분으로 올린다. 같은 분으로 접히거나 순서가 겹치는 구간은 거절한다. 각 원본 공수의 소수값은1/100자원분 격자로 투영하고, 최대 나머지·앞 구간 우선 순서로 원본 총공수의 반올림값과 합계를 맞춘다. 부동소수 decoder의 미세 오차는 십진 정규화한 뒤 비교한다. 합계 불일치·음수·비정상 수치는 거절한다.

각 배정의 기준점은 원본 작업 시작이다. 뒤늦게 시작하는 배정의 앞부분은0구간으로 유지한다. 작업 기간은 원래 기간과 마지막 계획 구간까지의 작업 달력 창 중 큰 값을 분으로 올려 사용한다. 분할/유휴 구간 때문에 원본의 ‘활성 기간’과 새 사본의 ‘기간 창’이 다를 수 있으며 이를 명시한다. 원래 시각·기간은 original.mpp에 남는다.

계획 검산은 기존 native 작업·자원 달력/휴일·정수 배정률 변환을 사용한다. 가용 시간 없는 양수 공수·배정률 상한 초과·검산 불일치는 거절한다. 일정은 PPM 논리 계획과09:00 날짜 시작 기준으로 계산한다. 원본의 절대 배정 날짜·분 미만 모양이나 Microsoft Project의 재계산 결과를 그대로 재현한다는 의미가 아니다.

미리보기 상단에 채택 배정/행 수, 실제공수/초과근무 제외 수, 분 경계 올림·기간 창 투영·시작 기준 정렬·공수 반올림 수를 표시한다. 확인 후에만 기존 새 폴더 게시와 사본 열기를 수행한다. 취소·stale/session·권한·읽기 전용 검사를 유지한다.

## 저장·배포와 검증

곡선 메타데이터와 구간은 기존 schema36으로 저장·재열기·undo·복구한다. XML 계획 시간대별 공수와 XER21값으로 다시 교환할 수 있으며 XER 집계 손실은 기존 진단을 따른다. 새 native schema나 관측 데이터 형식은 추가하지 않는다.

bridge와 manifest는 protocol2, 계획 정책은 `source-regular-minute-v1`이다. 앱과 reader bundle을 함께 갱신해야 한다. 예전 protocol1 bundle을 조용히 사용하지 않고 구성 오류로 거절한다. 엔진/JDK·의존성 lock과 LGPL 대응 소스/고지·오프라인 별도 프로세스·메모리/출력/취소/시간 제한은 유지한다. 배정당1,024구간, 전체100,000구간과16MiB XML 한도를 검사한다. 기존 bundle의 검증된 JAR/source 경로를 그대로 지정해 bridge만 다시 빌드할 수도 있다.

공개 실제 MPP의 수동 곡선2개와 정규 계획9개 배정, 실적/초과근무 제외, 복잡한 MPP9/12/14 달력의 명시 거절을 검사한다. 기존 MPP8/9/12/14 판독 회귀도 함께 실행한다. 같은 고정 decoder의 원본 객체를 bridge/writer와 별도로 읽고 독립 civil-minute 계산으로10,080개 자원분·공수/0구간을 대조한다. 이 검사는 실제 MS Project 실행을 대신하지 않는다. 근거는 [MPXJ 시간대별 자료 문서](https://www.mpxj.org/howto-use-timephased/)와 고정16.10.0 source이다.
