# 입력 저장과 일정 계산 상태

2026-11-17 · UX-W04. 주 창의 작업 표 위에 파일 상태와 일정 상태를 따로 표시한다.

**파일**은 현재 입력·보고 이력의 명시 저장 여부다. 처음 저장 필요, 미저장 변경, 저장됨,
새 파일에 저장 필요, 읽기 전용을 구분한다. 자동복구 저장은 별도다.
옆의 **파일 저장**은 기존 저장 명령을 실행하며 새 파일·복구 사본·이전 형식·읽기 전용이면
기존 정책에 따라 저장 위치를 정한다. 저장 실패나 파일 선택 취소를 성공으로 표시하지 않는다.

**일정**은 현재 입력에 대한 계산 상태다. 계산 필요, 재계산 필요(이전 결과 오래됨), 계산 중,
현재 입력의 계산/재예측 완료, 입력 불완전, 충돌, 계산 취소를 구분한다.
상태일이 있으면 버튼은 **재예측 · F9**, 없으면 **일정 계산 · F9**다.
기존 계산 명령과 같은 입력 검증·비동기 처리·취소·오래된 결과 차단을 사용한다.

- 파일을 저장해도 일정은 계산되지 않는다. 기준선·보고·계획을 변경했다면 현재 입력으로 다시 계산한다.
- 일정을 계산해도 파일은 저장되지 않는다. 계산 완료 뒤에도 미저장 변경이 남아 있으면 파일을 저장한다.
- 저장 파일을 재열면 입력과 이력은 유지되지만 세션 계산 결과는 다시 계산한다.
- 입력 불완전·충돌은 완료로 표시하지 않는다. 진단 보기에서 원인을 확인하고 수정 후 다시 계산한다.

본문의 다음 행동 안내는 두 상태를 함께 보고 저장·계산·진단 확인을 제안한다.
계산 결과의 자원 검증 여부와 상세 진단은 기존 하단 안내에 유지한다.
높이520 미만의 작은 창에서는 표의 작업 행과 명령 공간을 확보하려고 본문 상태 영역을 숨긴다.
툴바 저장/F9와 하단 저장·일정 안내는 유지한다.

[주간 갱신](weekly-update.md)에서 실적을 입력한 뒤 **입력 마치고 재예측**을 누르면
창을 닫고 현재 입력의 일정을 계산한다. 이 버튼은 파일을 저장하지 않는다.
목록 닫기나 입력 초안 취소만으로 재예측하지 않으며, 먼저 제출한 보고는 유지한다.
주 창에서 계산 결과와 파일 상태를 확인하고 저장한다.
