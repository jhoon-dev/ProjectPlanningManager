# 네트워크 다이어그램과 관계 탐색 (GAP-08)

2026-11-03 다음 단계 개발 요청의 native 첫 증분이다. 보기 메뉴에서 비모달 네트워크 창을 열고 표/간트의 선택 작업을 중심으로 관계를 검토한다. 그래프에서 선택한 작업의 전체 직접 선행/후행은 가상화된 목록으로 조회하며, 표·간트에서 찾기 또는 더블클릭은 안정 ID로 연결한다. 숨겨진 작업을 찾을 때는 기존 선택 API의 WBS/검색/분류 필터 해제를 명시한다.

## 계산·표시 계약

- 전체 프로젝트의 기존 일정 엔진을 worker에서 새로 실행한다. 현재 계획/상태일 이후 잔여·실제 날짜, 엔진이 산정한 여유/임계·driving 정보를 표시한다. 화면에 보이는 부분 그래프에서 CPM이나 임계를 다시 계산하지 않는다.
- FS/SS/FF/SF와 부호 있는 지연을 원본 관계대로 표시한다. S/F 연결 포트와 분 단위를 명시한다. driving은 엔진의 binding predecessor 정보이며 임계와 구분한다. 평준화는 별도의 자원 순서 연결과 여유를 표시한다. 완료 실적의 미래 여유는 해당 없음, 계산 불가 결과의 여유·driving은 미산정으로 표시한다.
- 주변, 전체 선행/후행, driving 선행/후행, 전체 작업의 제한된 묶음을 제공한다. 제한을 넘으면 생략 수와 각 카드의 생략 관계를 명시한다. 직접 관계 목록은 표시 한도와 독립적으로 전체 인접 관계를 제공한다. 원본 번호/작업 ID로 탐색하고 이름 검색은 후보 수를 제한한다.
- 기본 80개, 최대 200개 카드/600개 선으로 화면을 제한한다. SCC 기반 구조상 순환과 순환선을 구분하며 배치 계층은 날짜 축이 아니다. 구조상 순환 표시와 엔진의 계산 상태를 별개로 기록한다. 화면에 없는 관계를 없어진 논리로 해석하지 않는다.
- 열기 당시의 표 표시 범위를 표시하고 명시적으로 갱신할 수 있다. 표시 작업만 보기 역시 계산 대상을 바꾸지 않는다. 기준 작업은 범위 밖이어도 유지하고 범위 밖임을 알린다.

## 세션·데이터 경계

불변 snapshot·문서 ID/revision·session·요청 세대를 검사한다. 문서 편집/재열기/undo로 이전 그림과 탐색을 무효화하고 최신 입력 재계산으로 갱신한다. 취소한 worker 결과를 반영하지 않는다. 모델/장면 생성은 제한된 표시 대상으로 수행하며 읽기 전용 문서에서도 탐색할 수 있다. 원본 일정·기준선·실적·원가·파일 schema와 일반 편집 이력을 바꾸지 않는다.

관계 편집/드래그, 네트워크 인쇄/내보내기, 조직/다중 프로젝트 네트워크, 영속 배치 저장과 고급 선 묶기는 후속이다. 대용량은 1천/1만 고정 입력의 계산·표시 선택·장면 생성 시간을 측정하며 작은 fixture의 임계 결과를 전체 제품/외부 제품 동등성으로 확대하지 않는다.

## 사용 흐름

보기 → 네트워크 다이어그램…에서 표 선택을 기준으로 연다. 카드 선택은 상세/직접 관계 목록을 바꾸고, 목록 더블클릭·중심 이동은 기준 작업을 바꾸고 카드 더블클릭은 표·간트로 이동한다. 원본 번호 또는 ID/이름 검색 후 후보를 중심으로 이동할 수 있다. 표·간트 이동 버튼은 기존 필터를 해제한 뒤 해당 안정 ID를 선택한다. 확대/축소 버튼과 Ctrl+휠, 손바닥 드래그, 맞춤/100%를 제공한다.

빨간 카드는 엔진의 임계 작업, 주황선은 엔진의 driving 관계, 보라색은 구조상 순환이다. driving은 native 엔진이 기록한 binding predecessor의 의미를 유지한다. 특히 프로젝트 시작 경계로 보정된 관계의 판정도 그대로 표시하며 별도 재판정하지 않는다. `+/-…m`은 관계 지연의 분 단위다. 카드의 숨은 관계 수와 직접 관계 목록은 화면 밖 관계를 검토하는 수단이다. 전체 모드의 이전/다음은 기준 카드를 유지하며 나머지 작업을 원본 순서로 나눈다.

입력 변경 시 그림을 비우고 최신 계산을 요구한다. 표 범위 갱신은 현재 검색/필터 결과를 다시 캡처하며 원본 일정 계산에는 영향을 주지 않는다. 일반 저장만으로 유효한 그래프를 폐기하지 않으며 재열기는 같은 ID/revision이어도 다른 세션으로 처리한다.

## 로컬 검증

[Windows 전체 CTest 77개·독립 출력·1천/1만 관측과 화면](validation/network-diagram-2026-11-03/README.md)을 통과했다. native 작은 수치/관계·필터·생략·순환·취소/session·표/간트 연동과 원본 불변을 확인했다. offscreen 관측을 실제 데스크톱/다른 OS 수용으로 확대하지 않는다.

B 진척 정책 채택 상태에서 진행 중 작업의 수신 관계는 원본 구조에 남기되 비활성으로 표시한다. 점선·설명으로 구분하고 driving 경로에서는 제외한다. [진척 정책 채택](progress-policy-adoption.md).

평준화 후 자원 연결을 별도 종류/자원 ID·단위와 함께 표시하고 driving 탐색에 포함한다. 구조 순환 판정은 원본 관계를 기준으로 유지한다. [계산 기준](leveling-float.md).

교차 분할의 자원 연결에는 실제 release/acquire 시각을 tooltip으로 표시한다. A 앞 구간→B→A 재개 구간은 작업 수준에서 왕복할 수 있지만 원본 논리 순환으로 분류하지 않는다. 새 구간 관계의 driving은 선행을 작업 달력 1분 늦추었을 때 현재 후행 구간을 지킬 수 있는지로 판정한다. 작업 단위 그림은 실행 구간망의 투영이며 구간 편집은 지원하지 않는다.

엔진1.3~1.8의 인계선은 현재 배치의 참고 관계이며 재분할 후보가 같은 선을 유지할 필요는 없다. 임계는 새 총여유, 자원 driving은 현재 날짜에서 1분 지연 시 실제 용량 충돌을 기준으로 한다. 작업별 증인의 다른 날짜는 진단에서 확인한다. 1.4~1.8 증인에서 생략된 작업은 현재 날짜를 유지한다. [정의](leveling-float.md).
