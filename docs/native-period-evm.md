# native 기간 EVM

2026-11-08 · NEV-01~06. 승인 기준선과 native 보고 원장을 사용해 일·주·월별 PV/EV/AC 증감을 계산한다. 기본 계산은 외부 XER EV/PV와 독립적이며 [명시 채택](external-xer-evm-adoption.md)이 있으면 해당 기준선·작업의 선택 지표를 대체한다. 기간 EVM 자체는 읽기 전용 파생 보고다. 채택/철회 이력의 조건부 schema29는 별도 XEA 계약을 따른다.

## NEV-01 범위와 경계

원가 → native 기간 EVM…에서 승인 기준선, 현재 WBS 작업 범위, 날짜 구간과 일/주/월을 선택한다. 전체 프로젝트는 삭제된 기준선 작업도 포함하고 현재 WBS 선택은 해당 현재 작업 ID와 기준선의 교집합이다. WBS 집계는 기준선 구조를 사용하며 각 작업은 한 번만 합산한다. 기준선 밖 신규 작업은 EVM에 포함하지 않는다. 통화가 다른 기준선은 계산하지 않는다.

주 단위는 월요일~일요일, 월 단위는 civil 월이며 시작/종료 필터로 첫/끝 기간을 자른다. 시작일 00:00 직전이 개시이고 종료일 다음 날 00:00 직전이 마감이다. 경계 정각의 보고/일시점 예산은 다음 기간에 속한다. 현재 상태일이 기간 안이면 마감을 상태 시각으로 자른다. 이후 기간의 EV/AC는 미정이며 PV만 계획으로 표시한다. 9999-12-31은 지원 마지막 분23:59를 포함한다.

## NEV-02 native 누계와 기간 증감

PV는 선택 기준선의 동결된 작업·일정·달력·단가/고정비·귀속을 사용한다. EV는 기존 native 측정법인 물리 진척/Steps 가중 진척 또는 완료0/100을 따르고 AC는 비용 보고의 실제 누계다. 상태 시각 이하의 최신 보고를 선택하며 같은 상태 시각의 정정은 원장 뒤쪽 기록이 우선한다. 이전 보고값은 다음 보고까지 유지하며 보간하지 않는다.

명시 XER 채택이 있으면 선택한 EV/PV는 외부 기간과 개시 누계로 확인한 경계값을 사용한다. 구간 내부·공백/범위 밖의 미확인 경계는 미정이며 native 값과 더하거나 자동 혼합하지 않는다. AC·날짜 배분·BAC는 기존 규칙을 유지한다. 채택 이력과 활성 기간/출처 표를 함께 출력한다.

기간 PV/EV/AC = 마감 누계 − 개시 누계다. 개시 보고가 없거나 명시 공란이면 해당 증감은 미정이다. 날짜 배분 원장이나 미보고 구간으로 누계/개시값0을 만들어 내지 않는다. 명시0은 알려진 값이다. 음수 증감은 과거 보고의 정정으로 그대로 표시한다. 기준선 예산0의 EV0은 기존 EVM 규칙을 따른다.

## NEV-03 지표와 합산

기간 CV=기간EV−기간AC, SV=기간EV−기간PV다. 기간 CPI=기간EV/기간AC, SPI=기간EV/기간PV는 비음수 EV와 양의 분모일 때만 계산한다. 음수 정정이나0/미정 분모의 효율은 미정이다. 프로젝트/WBS 지표는 작업 누계를 먼저 합산한 뒤 계산하며 작업별 비율을 평균하지 않는다. 누락값은 전체 합계에도 전파한다. 금액은 정수 최소단위이며 지원 범위를 넘는 합계는 미정으로 표시한다.

마감 EAC/ETC는 마감 누계와 사용자가 선택한 기존 추정식을 사용한다. 기간 CPI를 누계 추정식에 대입하지 않는다. SV 금액을 날짜 지연으로 해석하지 않는다.

## NEV-04 날짜 원장 대사와 근거

별도 날짜 대사에는 현재 조회 상태일에 알려진 최신 기간 원가를 실제 날짜별로 합산한다. 배분이 없는 기간은 보고된 배분 합계0이며 실제 발생원가0의 증거가 아니다. 기간 누계 AC 증감과 이 날짜 배분의 차이를 표시한다. 차이에는 날짜 미배분·보고 지연·이전 날짜 정정·기간 밖 누계 보고가 섞일 수 있으므로 이를 기간 실제원가로 재분배하지 않는다. 날짜 배분은 누계 AC에 이미 포함된 금액이다.

작업별 개시/마감 원가 보고 ID와 EV 근거 ID, 기준선/문서/revision/상태일·생성시각·날짜 경계/집계 정책을 함께 출력한다. 이후 상태일의 날짜 배분 정정은 현재 날짜 대사를 다시 표시하지만, 이전 마감 누계에는 그 시각보다 미래인 보고를 적용하지 않는다. 같은 과거 상태일의 후속 정정은 현재 원장 기준으로 재표시한다.

## NEV-05 화면·출력·보존

기존 보고서의 가상 표·비동기 계산·XLSX/PDF 출력과 고정 footer를 사용한다. 계산 중 기준선/기간/단위 변경은 이전 결과를 폐기하며 문서/revision/session 변경에는 재계산을 요구한다. 읽기 전용 문서에서도 조회/내보내기를 지원한다. 계획·기준선·원가/기간/진척/Steps 원장과 원본 XER는 변경하지 않는다. 저장/재열기·복구 후 같은 원장으로 다시 계산한다.

최대3,660기간, 프로젝트/작업/WBS 합계20,000행과 기존 출력100만 cell 한도를 적용한다. 중간 계산은 협조적 취소를 지원하며 한도 초과는 범위를 줄여 다시 계산한다.

## NEV-06 검증과 후속

경계·부분 기간·휴일/누진 단가·고정비 귀속, 누락/0/음수 정정·보고 순서·Steps/0-100, WBS/코호트/통화·미래·한도·취소·원본 불변과 저장/복구, UI·독립 정수/Decimal/XLSX/PDF 및 전체 회귀로 검증한다. [전체130/130·집중21/21·독립810개 수치 및 실행 증거](validation/native-period-evm-2026-11-08/README.md)를 따른다.

외부 XER EV/PV의 native 채택은 [XEA](external-xer-evm-adoption.md)로 구현했다. 예산/EV 사용자 기간과 당시 지식 revision 마감 잠금은 [CFP](custom-financial-periods.md)로 구현했다. 기간 지정액은 native 누계와 별도이며 원장과 과거 마감을 보존한다. 새 버전 일정 병합·통화 변환과 실제 P6/MS Project 재계산·재저장은 후속 범위다.
