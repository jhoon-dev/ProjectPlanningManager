# FixedWork/FixedUnits 곡선 역산

2026-11-06. WCI-01~05, GAP-04/11·PRD-03/05/06/07/08·J-03/05/06/08/09/14/16에 연결한다. **자원 → 기간별 계획 배정·자원 곡선…**과 기존 작업의 기간/공수 입력을 사용한다. 고정 기간의 구간에 이어 고정 공수/고정 단위의 곡선을 지원한다. Steps는 허용하며 지원 활동의 직접 자원/공수 역산은 별도 범위다. 초기 범위에서 제외했던 FixedWork/FixedUnits 날짜 고정 잔여 목표는 2026-11-08 [후속 계약](dated-effort-targets.md)으로 지원한다.

## WCI-01 입력별 유지값

| 유형/편집 | 유지하는 입력 | 다시 계산하는 값 |
|---|---|---|
| FixedWork 기간 입력 | 명시 총공수 | 실제 근무분의 곡선 배정률. 요청 기간·공수와 최종 논리 일정을 함께 검산 |
| FixedWork 공수 입력 | 기본률·곡선 정의 | 완료 시각과 계산 기간 |
| FixedUnits 기간 입력 | 기본률·곡선 정의 | 해당 기간의 실제 공수. 공수 기준을 해제하고 기간 기준으로 전환 |
| FixedUnits 공수 입력 | 기본률·곡선 정의 | 완료 시각과 계산 기간 |
| FixedUnits 배정/곡선 편집 | 변경 전 논리 계획의 양수 공수 | 변경된 곡선으로 완료 시각. 기간 기준이었다면 공수 기준으로 전환 |
| FixedDuration 공수 입력 + 곡선 | 기간 | 곡선 배정률과 정확 총공수 |

기본률과 구간은 명시적으로 편집할 수 있다. ‘고정 단위’가 사용자의 곡선 수정까지 금지한다는 의미는 아니다. 기간 기준의 미정/0 기간은 곡선 입력을 거절한다. 공수 기준 0은 실행 없는 시점이며 저장 곡선을 보존한다. 0공수의 양수 기간 역산은 불가하고, 0공수/0기간은 허용한다.

## WCI-02 공통 실행과 정확 역산

작업 달력 근무분의 상대 구간·구간 밖 기본률·명시0을 재사용한다. 작업/자원 달력·각 휴일·점심·수동 중단을 교차한 실제 구간에서 공수를 적분한다. 공수 기준은 목표에 처음 도달하는 분에 완료하고, 마지막 분의 수요를 정수1/100 자원분까지 줄여 전체 공수를 정확히 맞춘다. 여러 자원의 마지막 분은 비례 배분 후 안정 자원 ID 순으로 나머지를 배분한다. 선행0%나 자원 비근무 시간에도 상대 곡선 위치가 지나가므로 곡선 작업의 시작은 작업 달력의 논리 시작에 고정한다.

같은 달력의 자원만 있는 경우에는 상대 곡선 적분으로 구한 기간이 이동에 대해 불변임을 이용한다. 서로 다른 달력에서는 실제 후보의 교집합을 사용한다. 늦게 시작해 더 빨리 끝나는 경우가 있으므로 완료 조건 역산·시작/완료 조건의 교집합·직렬 평준화에 단조성 가정을 쓰지 않는다. 공수 곡선의 논리/자원 여유는 기존 유한 후보 탐색에서 실제 실행을 검산한다. 논리 여유는 자원 가용량을 제약으로 삼지 않으며, 자원 여유는 용량·현재 인계 순서를 검사한다. 총여유의 최후 날짜는 작업별 증인이며 모든 작업에 동시에 적용하는 일정이 아니다.

기간 역산은 기존 양수 수요의 상대 비중을 목표 공수에 비례해 정수 배정률로 만든다. 나머지는 끝쪽 실제 근무분에 1%씩 배분한다. 명시0과 교집합 밖/현재 기간 밖 구간은 유지하고, 목표 구간의 실제 근무분만 덮어쓴다. 요청 끝에 양수 자원 근무분이 없는 경우 등 정확히 실현할 수 없는 기간은 거절한다. 가용률 초과를 묵시적으로 잘라내지 않으며 부하 분석으로 별도 확인한다. 배정률0~100,000%, 배정1,024/전체100,000구간 한도를 유지한다. 기본 배정률 자체는 그대로 보존한다.

역산은 현재 논리 계획의 날짜·달력에서 인증한다. 이후 달력·선후행·곡선을 바꾸거나 평준화로 이동하면 FixedWork는 총공수를 다시 맞추고 기간이 달라질 수 있다. 여러 FixedWork의 일괄 기간 편집은 모든 요청 기간으로 먼저 같은 논리 계획을 구성한 뒤 역산하고 최종 계획을 재인증한다. 행/명령 순서에 의존하지 않는다.

## WCI-03 잔여·여유와 한도

기간 기준 잔여의 기존 뒤쪽 곡선 정책은 유지한다. **공수 기준 잔여는 명시 보고된 잔여 공수를 현재 미래 실행의 상대0분부터 적분**한다. 계획의 경과 기간이나 관측 실제공수를 상대 시간 위치로 추정하지 않는다. 실제 시작/완료·실제 소요·실제공수/원가·기간 실적 원장을 수정하지 않는다. 이는 계획의 실행 곡선을 잘라 과거 실적을 만들어내는 기능이 아니다.

가용량 미정·증인 인증 실패·한도 초과는 여유 미산정 사유를 남긴다. 논리 여유 실패도 유효한 전진 날짜를 보존하고 미산정 값을 빈 셀로 표시한다. 기존 후보250,000·판정2,000,000·후보 구간2,000,000 한도, 새 완료 조건/직렬 전진 탐색2,000,000회 한도와 worker 취소를 적용한다. 달력 지평 밖/필요 배정률 초과·불가능한 기간은 명시 오류다.

## WCI-04 편집·저장·출력

화면은 입력 기간과 계산 기간을 구분한다. 곡선 미리보기와 실제 문서 적용은 같은 순수 편집 함수를 사용한다. 문서 적용은 한 undo/redo·dirty/revision, PreparedEdit 취소/stale/session/읽기 전용 보호를 따른다. 계획 공수→배정률 하위 창은 기존 고정 기간 범위를 유지한다. FixedWork/FixedUnits에서는 곡선 편집과 작업 기간/공수 입력을 사용한다.

새 영속 값 없이 기존 Assignment.periods를 사용한다. 현재/동결 입력에 고정 공수·단위 곡선이 있거나 해당 평준화 정책이 이력에 남으면 조건부 **schema24**를 쓴다. schema1~23은 계속 읽고 새 조합은 거절한다. 과거 고정 기간 곡선 엔진·균등 역산 반올림 정책은 유지한다. 새 엔진은 `jobs-effort-work-periods-1.0` / 채택 `jobs-adopted-work-periods-1.0`, 정책은 `serial-effort-work-periods-v1`이다. 기존 날짜 고정 입력과 함께 있으면 잔여 엔진을 `jobs-dated-work-periods-1.0`으로 식별한다.

기준선/시나리오는 원래 곡선·계산 결과를 동결한다. 현재 곡선 편집은 기존 평준화 무효화·결정 원장 정책을 따른다. native 사본/복구·Usage·유효 단가 원가·부하·보고서는 같은 실행 구간을 사용한다. XML/XER는 계속 기본률/명목 기간 투영과 곡선 손실을 명시하고 source.ppm에 원본을 보존한다.
