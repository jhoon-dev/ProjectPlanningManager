# 인쇄 설정·WBS 요약·관계선과 네트워크 확장

2026-11-05 후속 증분. 기존 일정표 인쇄·읽기 전용 네트워크 탐색을 확장한다.

## 설정과 저장

일정표 인쇄 창의 **설정 문서에 저장**은 용지/방향/여백/글자/표·이름 폭/기간 단위/자동·수동 날짜/범위 종류/기준선 표시/WBS 요약/관계선과 네트워크 맞춤·타일 배율을 저장한다. 실제 선택 작업 ID, 필터 결과, 프린터 이름·파일 경로·출력 ID는 저장하지 않는다. 설정 변경만으로 자동 저장하지 않으며 읽기 전용 문서는 임시 설정으로 출력할 수 있다.

설정 `Project.printPreferences`와 배치 `Project.networkPositions`는 **계산 입력 PlanInput 밖**의 문서 표시 정보다. 문서 dirty/revision·undo/redo·사본·복구에 포함하고, 기준선/시나리오 입력·실적·비용·평준화 채택과 결정 원장을 바꾸지 않는다. 유효한 일정 캐시는 revision만 갱신해 유지한다. 설정/배치가 있을 때 조건부 schema18, 없을 때 기존 writer를 유지한다. schema1..18과 recovery projectSchema18을 지원하고 구 schema의 새 속성은 거절한다.

값/참조/중복·정수·알 수 없는 속성을 검증한다. 배치는 현재 작업의 안정 ID당 하나, 최대 10,000개, 좌표 ±1,000,000 범위다. 작업 삭제 시 해당 좌표도 같은 undo 단위에서 제거하고 복제 작업은 자동 배치를 사용한다. 출력 설정은 기존 페이지 범위를 따른다.

## 일정표의 WBS 요약과 관계선

인쇄 창의 **WBS 요약(표시 범위)**은 선택/필터를 통과한 출력 작업과 그 조상 WBS만 집계한 요약 블록을 앞에 둔다. 원본 작업 행의 정렬은 유지한다. 작업 수와 활성 일정의 최소 시작/최대 완료, 선택 기준선의 범위를 표시한다. 기준선은 날짜가 있는 출력 작업 부분만 묶으며 미승인 새 작업에 기준선 값을 만들지 않는다. 기간·여유·진척률을 합산하거나 전체 WBS가 포함된 것으로 표시하지 않는다. 요약에는 임계/여유를 새로 계산하지 않는다.

**관계선**은 전체 프로젝트에서 계산한 유효 날짜를 사용해 FS/SS/FF/SF의 S/F 끝점을 연결한다. 요약 행에는 관계를 만들지 않는다. 두 끝점이 출력 범위에 있는 관계만 그리며, 범위 밖/날짜 미산정 수를 출처에 기록한다. 다른 세로 페이지로 넘어가는 관계는 원본 번호·종류·지연 참조로 표시한다. 기간 밖 선은 시간축 경계에서 잘리고 전체 관계 참조와 정확한 끝점 시각을 출처에 남긴다. 진행 중 작업의 시작측 수신 관계는 잔여 재개 시각에 연결한다. 진척 정책으로 비활성인 수신 관계와 완료 작업의 참고 수신 관계는 점선·설명으로 구분한다. 논리 관계와 평준화 자원 인계선을 혼동하지 않는다. 이 일정표의 새 화살표는 원본 논리 관계다.

## 네트워크 편집과 배치

**선택 작업 관계 편집**은 선택 작업의 모든 원본 수신 관계를 편집한다. 선행 원본 번호 또는 안정 ID, FS/SS/FF/SF, 부호 있는 근무분 지연을 입력하고 기존 일괄 작업 편집 worker로 원자적으로 적용한다. 자기 참조·중복·순환·잘못된 ID/지연은 기존 검증을 따른다. 자원 인계선은 계산 결과이므로 편집 대상에서 제외한다. 기준선·실적 보호, 평준화 무효화 원장·undo, session/revision·취소·읽기 전용을 유지한다.

카드를 드래그하면 초안 배치만 바뀌고 놓았을 때 선을 다시 연결한다. **배치 문서에 저장**은 표시 카드 좌표를 저장하며 다른 묶음의 저장 좌표를 보존한다. **자동 배치**는 현재 묶음 초안만 자동 위치로 되돌리고, **저장 배치 초기화**는 문서의 전체 저장 좌표를 제거한다. 저장/초기화는 undo 가능하다. 저장 좌표가 없으면 기존 SCC/계층 배치를 사용한다. 배치 간격은 날짜/기간 축이 아니다.

## 네트워크 출력

**네트워크 미리보기·인쇄**는 현재 표시망(최대 200카드/600선)을 GUI에서 벡터 QPicture로 캡처한다. 전체 프로젝트 계산 결과의 표시 부분이며 생략 관계/범위를 명시한다. 한 장 맞춤 또는 25~200% 타일 출력, A4/A3·방향·여백·쪽 선택과 PDF를 제공한다. 카드에서 축약한 전체 작업명/ID와 표시 관계는 출처 쪽에서 보존한다. 출력 ID/UTC·문서/revision·엔진/정책과 저장 상태를 캡처한다.

미리보기·PDF·프린터는 같은 불변 벡터·페이지 배치를 쓴다. 글자와 QPicture의 장치 DPI 변환을 정규화한다. 최대 2,000쪽/64MiB PDF/16Mi 문자 출처를 허용한다. 프린터는 미리보기와 용지/방향/최소 여백이 일치해야 하며 이 증분의 네트워크 인쇄는 정방향 1부를 지원한다. 다른 복사/순서는 명시적으로 거절한다. 장치 제출 전 문서/session/revision을 다시 검사하고, 시작한 출력은 고정 스냅샷을 사용한다. PDF는 새 파일명에 원자적으로 저장하고 취소/오류 시 게시하지 않는다.

조직/다중 프로젝트 네트워크, 고급 선 묶기·충돌 없는 배치 최적화, 네트워크에서 실행 구간/자원 인계선 편집은 후속이다. XML/XER에는 설정·배치를 매핑하지 않고 손실 진단과 native source.ppm에 보존한다. 실제 프린터/다른 OS 검증은 PDF·가상 프린터 검증과 구분한다.
