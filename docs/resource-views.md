# 자원 그룹·필터와 저장된 보기

2026-11-11 후속: [XML 계산식](xml-external-formulas.md)의 Resource 결과도 현재 보기의 형식별 비교·그룹·보고서에 사용한다. 활성 값의 직접 편집을 차단하고 오류와 미설정을 구분한다.

2026-11-11 후속: [요약 roll-up](xml-roll-up.md)의 Resource 규칙을 현재 필터의 자원 그룹에 적용하고 그룹 필드 열과 별도 보고서 표에 표시한다. 미배정 자원의 포함 여부도 현재 보기 조건을 따른다.

2026-11-06. 자원 → **자원 그룹·필터 · 저장된 보기…**. RV-01~04, GAP-03, PRD-02/06/07/08, J-02/05/14/16에 연결한다.

- 작업 보기와 별도로 자원별 고유 행을 조회한다. 이름/ID 검색, 기본 가용률·종류·달력·배정 여부·자원 사용자 필드를 사용한다. 검색/포함은 대소문자를 구분한다. 필터 최대 8개를 AND로 적용한다.
- 같음/표시 이름 포함/미설정/설정됨과 숫자·날짜의 작음/이하/큼/이상을 지원한다. 목록은 UI에서 이름을 입력하고 안정 옵션 ID로 저장한다. 숫자·날짜는 정규 형식으로 보존한다. 미설정·빈 텍스트·숫자 0·미정 가용량·0% 가용량을 구분한다.
- 최대 3단계로 그룹화하고 그룹별 자원 수를 표시한다. 기본 가용률과 임의 사용자 필드를 합산하지 않는다. 그룹은 원시 ID/값의 오름차순, 지정 정렬은 형식에 따른 숫자/날짜/문자 비교다. 미설정은 항상 마지막, 동률은 자원 ID로 결정한다. 그룹 토큰은 미설정과 명시한 빈 값을 구분한다.
- 현재 검색·그룹·필터·정렬을 이름 있는 자원 보기로 저장/갱신/삭제한다. 최대 64개, ID/이름 중복을 거절한다. 열거된 설정만 저장하며 작업 보기/계산 입력과 분리한다. 참조 중인 자원 필드/옵션 삭제는 원자적으로 거절한다. 필드/옵션 이름 변경은 ID 조건을 유지한다.
- 화면 탐색은 문서를 수정하지 않는다. 보기 저장은 한 번의 undo/redo·dirty/revision을 가지며 일정·원가·기준선/시나리오와 평준화 채택을 바꾸지 않는다. native 조건부 schema21과 복구/사본을 지원한다. schema20 이하는 새 보기를 거절한다.
- 소유 스냅샷의 비동기 조회·취소·세대 검사를 사용한다. 문서/세션/revision/권한 변경은 저장/출력을 차단하고 명시적인 최신 문서 재조회로 복구한다. 읽기 전용에서는 로컬 조건 변경·조회·출력만 허용한다.
- 보기 XLSX/PDF는 같은 필터 결과의 고유 자원별 한 행과 조건 명세를 내보낸다. 숫자 필드는 수치 셀, 미설정은 기존 보고서의 ‘미정’ 표시, 빈 텍스트는 ‘(빈 문자열)’로 구분한다. 그룹 열은 분류이며 집계 행을 다시 합산하지 않는다. 출력 셀 한도는 1,000,000개다. XML/XER는 보기 미지원 손실을 공개하고 source.ppm에 보존한다.

수용 검사: 형식별 비교·AND·안정 그룹·미설정/빈 값/0, 사전 이름 변경/삭제 보호, 저장/dirty/undo·일정/동결 불변, schema/복구·읽기 전용/stale/역할 철회, 1만 자원 projection과 UI·독립 출력 판독. [통합 검증 기록](validation/professional-fields-2026-11-06/README.md)을 따른다.
