# 작업·자원 시간축 Usage

2026-11-03 후속 [기간 실적 입력/정정](period-actuals.md)을 추가했다. Usage의 보고 실제공수/보고 실제원가는 명시적으로 제출한 날짜/자원별 관측분만 합산한다. 누계 AC·전기간 배분·미배분은 별도 대사하며 추정 배분하지 않는다. 기간 실적 원장만 추가된 파일은 schema 11이며 평준화/진척 정책 선택이 있으면 schema 12/13을 사용한다.

2026-11-03 사용자 후속 개발 요청에 따른 GAP-04의 첫 조회 증분이다. 작업→배정과 자원→배정 계층에서 계획·승인 기준선·상태일 이후 잔여의 공수와 원가를 일/주/월로 조회한다. 후속 기간 실적 입력은 별도 불변 원장·명시 누계 대사 계약으로 연결한다.

## 계산과 집계 계약

- 시작/끝 날짜는 포함한다. 일은 civil 날짜, 주는 월요일~일요일, 월은 달력 월이다. 양 끝의 주/월은 선택 범위로 잘라 표시한다. 근무구간은 반개구간이며 자정·휴일·작업/자원 달력 교집합·수동 분할은 기존 실행 구간을 사용한다.
- 모든 공수는 `%·분` 정수로 합산한 뒤 시간으로 표시한다. 100%의 60분은 1인시 또는 1장비시다. 두 종류를 서로 합산하지 않는다. 미배정 작업의 배정 수요는 0이지만 필요한 인력/장비가 0이라는 뜻이 아니며 미배정 개수를 별도로 표시한다.
- 기준선은 동결한 입력·자원·단가·승인 당시 엔진의 검증된 일정으로 계산한다. 삭제된 기준선 작업/배정도 안정 ID의 합집합으로 표시한다. WBS 범위는 현재와 기준선 각각의 해당 WBS 하위 작업 ID 합집합이다. 필터를 위해 전체 계산 그래프를 잘라내지 않는다.
- 기준선 미선택·상태일 미설정·일정 불완전/충돌은 해당 열의 미정이다. 산정 가능한 단계에서 존재하지 않는 작업/배정이나 무수요 날짜는 0이다. 단가·고정비 미설정 및 한도 초과는 해당 원가를 미정으로 전파하고 알려진 0과 구분한다. 통화가 다른 기준선은 공수만 비교하고 원가는 환산하지 않는다.
- 현재 계획과 기준선 원가는 기존 원가 분석의 배정별·일별 유효 단가와 최소 통화단위 반올림, 고정비 시작/완료/균등 정책을 공유한다. 일별 금액을 먼저 확정하고 주/월로 더하므로 시간축 변경으로 금액이 바뀌지 않는다. 고정비는 별도 배정 행/자원 미배분 그룹에 한 번만 포함한다.
- 잔여 공수는 현재 선택한 진척 정책의 실행 구간이며 미채택 시 기존 retained remaining을 사용한다. 완료 작업은 0이며 실제 시작/완료와 원장을 변경하지 않는다. 잔여 배정원가는 잔여 공수에 미래 유효 단가를 적용한다. 집행 여부의 근거가 없는 고정비를 포함하지 않으며 EAC/ETC나 미래 지급액으로 해석하지 않는다.
- 누적 실제원가는 상태일의 최신 정정 보고를 고른 작업 총액이다. 명시한 기간/자원 실적만 관측 배분으로 조회하고 기존 미배분 누계를 날짜에 추정 배분하지 않는다. 보고 실제공수/원가는 입력한 부분만 합산하고 건수를 툴팁에 표시하며 미보고와 0을 구분한다. 누계 AC와 배분액은 다시 더하지 않는다. 실제 소요 기간에서 실제공수를 만들지 않는다.
- 각 계층은 동일한 고유 배정+고정비 명세를 집계한다. 상위와 하위 행을 다시 합산하지 않는다. 화면의 기간 합계는 표시 범위만 포함한다. 과부하는 기존 동시간대 부하 계산을 유지하며 Usage 공수 일평균으로 판단하지 않는다.

## 화면·출력·입력 보존

자원 → **작업·자원 시간축 Usage…**에서 WBS/기준선·날짜·일/주/월을 선택하고 조회한다. 작업/자원 계층 및 공수/원가 지표는 같은 계산 결과에서 전환한다. 열 너비를 조정하고 트리 행을 펼쳐 배정을 확인할 수 있다.

계산은 불변 스냅샷을 worker에서 실행한다. 취소/닫기·조건 변경은 협력 취소하고 문서 session/ID/revision/저장 상태가 달라진 결과는 표시·내보내지 않는다. 읽기 전용 문서에서도 조회·출력할 수 있다. 조회는 입력을 바꾸지 않으며 기간 실적 제출만 schema 11의 불변 원장에 추가한다.

XLSX/PDF는 고유 배정+고정비×기간 명세와 별도의 작업별 실제원가 누계를 출력한다. 상위 집계를 중복 행으로 내보내지 않는다. 출처 문서/revision·WBS·기준선·선택 기간·상태일·생성 UTC·저장 상태를 포함한다. 파일 게시 후에는 계산 당시의 명시된 스냅샷 출력물로 보존한다.

범위는 최대 7,320일·366개 기간이며 계층 확장 시 최악 크기를 포함해 100만 개 지표 셀로 제한한다. 출력은 기존 보고서 전체 100만 셀 한도다. 한도를 초과하면 기간/WBS를 좁히라는 진단으로 거절하며 일부 작업을 잘라 정상 합계로 내보내지 않는다.

작업·배정이 많은 프로젝트는 짧은 날짜 범위나 주/월 시간축, 좁은 WBS로 시작한다. 화면에서 조회 가능한 범위라도 열이 더 많은 출력 명세의 한도는 따로 적용한다.

## 검증과 수용조건

1. 반일/휴일/자정·주/월 경계·달력 교집합·분할·분수 배정에서 독립 정수 기대값과 기존 자원 수요 적분을 대조한다.
2. 배정→작업/자원→범위 합계와 일→주/월 합계가 같고 인시·장비시·고정비 중복이 없다. 유효 단가·일별 반올림은 기존 원가 분석과 일치한다.
3. 승인 후 단가/배정 변경·삭제된 기준선 작업·WBS 필터·상태일 이동·완료/진행·정정 실제원가에서 동결·미정/0·미배분 계약을 확인한다.
4. UI 계층/기간/지표 전환, 취소·오래된 결과·읽기 전용·입력 불변·내보내기를 검증하고 1천/1만 작업의 제한된 조회 범위를 측정한다.
5. XLSX/PDF는 독립 reader로 숫자·미정·합계·한국어·출처를 확인하고 전체 회귀를 실행한다. 미실행 플랫폼/제품 검증은 따로 기록한다.

로컬 실행·출력·화면·규모 측정과 미실행 범위는 [2026-11-03 검증 기록](validation/timephased-usage-2026-11-03/README.md)에 보존한다. 이 링크는 첫 조회 증분의 당시 기록이며 후속 기간별 실제 입력은 [입력 계약](period-actuals.md)의 별도 검증 기록을 따른다. 실제 제품 동등성의 증거는 아니다.

평준화 채택 후 계획 또는 잔여 실행 구간과 유효 단가로 Usage를 계산한다. 출처 표에 채택 정책·사유·시각과 자원 순서 여유 계산 기준을 기록한다. 계산 여부와 불가 사유는 진단에서 확인한다. 기준선의 계획 채택 설정은 동결 재생한다. [채택 계약](leveling-adoption.md).

잔여 실행 구간은 이제 현재 채택한 진척 정책을 따른다. 미채택 시 기존 잔여 논리 유지이고 B 채택 시 비활성 수신 관계를 반영한다. 출처 표에 담당자·사유·UTC·검토 문서를 기록한다. 선택이 있으면 schema13이며 계획/기준선 공수·원가와 실제 원장은 보존한다. [정책 채택 계약](progress-policy-adoption.md).

진척 정책+평준화를 함께 채택하면 잔여 배정 공수/원가는 조합의 배치 날짜를 따른다. 출처에 진척 정책과 평준화 근거를 함께 표시한다. 조합 및 정책을 동결한 시나리오는 schema14로 저장한다. [사용법](progress-policy-leveling.md).
