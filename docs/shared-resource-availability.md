# 공유 풀의 부분·열린 가용기간

2026-11-16 · SPA-01~06. **다중 프로젝트·공유 자원 → 공유 자원·연결 → 용량·달력 편집**에서 공유 풀의 전체 가용 경계와 기간별 가용률을 편집한다. 값의 단위는100%=1명/대이며, 기존 공유 공급·연결·달력을 유지한다.

| 입력 | 의미 |
| --- | --- |
| 가용 시작/종료 | `YYYY-MM-DD HH:mm`, 해당 분 포함. 빈칸은 그 방향에 제한 없음 |
| 기간별 가용량 | 한 줄에 `시작 ~ 종료=정수%` 또는 `?`. 빈 시작/종료는 열린 기간 |
| 기본/기간/날짜별 가용률 |0~10,000,000 또는 미정.0과 미정을 구분 |

예: ` ~ 2026-11-16 09:29=50`, `2026-11-16 09:30 ~ 2026-11-16 10:14=?`, `2026-11-16 10:15 ~ =200`은 종료 분을 포함한 세 기간이다.09:29는50%,09:30~10:14는 미정,10:15부터200%다. 같은 종료/시작 분은 겹치므로 앞 기간이09:29에 끝나면 다음 기간은09:30부터 쓴다.

- **SPA-01 의미/검증:** [로컬 가용기간](resource-availability.md)과 같은 civil 분·열린 경계·종료 포함을 따른다. 전체 가용 경계 밖은0이다. 경계 안에서는 **날짜별 예외 → 기간별 가용률 → 기본값** 순서다. 기간 공백은 기본값이며, 미정 기간이나 날짜를0으로 대체하지 않는다. 역전·겹침·중복 열린 기간·잘못된 시각/시간대 오프셋·음수/상한 초과를 거절한다. 풀별 기간은 최대10,000개다.
- **SPA-02 시점 조회:** [공유 잔여 가용량](shared-remaining-availability.md)의 공유 공급에 새 경계를 적용한다. 근무 달력의 휴무 시각은 설정이 미정이어도 유효 공급0이다. 전체 수요는 기존 명시 연결의 동시 수요를 유지한다. 확인된 수요/전체 수요/미정과 파일별 예측 상태일 규칙도 그대로다. 프로젝트 로컬 capacity/가용기간을 덮어쓰지 않는다.
- **SPA-03 기간별 부하:** 실제 수요 이벤트·달력 경계에 새 가용률 변경 분과 종료 다음 분을 추가해 과부하 시간·초과 공수·미정 가용 시간을 정확히 적분한다. 일별 한 값으로 대표할 수 없는 설정은 **시간별**로 표시한다. 이는 수요가 있는 구간에서 설정 가용률이 둘 이상이라는 뜻이며 미정 상수와 구분한다. JSON의 `variableCapacity=true`와 `capacity=null`,UI/XLSX/PDF의 시간별 표시가 대응한다. 과부하 계산에는 공유 달력의 유효 공급을 사용한다.
- **SPA-04 통합 평준화:** 공유 풀을 통합 일정의 자원으로 투영할 때 전체 경계·열린/부분 기간도 전달한다. 기존 로컬/공유 자원 달력 일치 조건과 공유 평준화의100,000% 상한은 유지하며 기간 가용률도 검사한다. 논리 통합 일정의 공유 부하·통합 출력에도 같은 공급을 적용한다. 원본 파일 날짜/배정은 변경하지 않는다.
- **SPA-05 화면/무효화/원자성:** 기간/경계 편집·재열기·취소를 지원한다. 겹침 검증 실패 후 수정해 적용할 수 있고 실패/취소는 이전 카탈로그를 보존한다. 기간 변경도 작업공간 세대를 증가시켜 진행 중 계산과 이전 조회/출력을 무효화한다. 공유 조회의 JSON/XLSX/PDF는 기간 공급과 미정 결과를 반영한다.
- **SPA-06 저장:** 새 공유 경계/기간 중 하나라도 있으면 `.ppmworkspace` **schema4**로 저장한다. 모든 공유 Resource에 nullable `availableFrom`/`availableTo`와 `availability:[{from,to,units}]`를 쓴다. schema4는 links/integrated/governance도 모두 보존한다. 값이 없으면 기존 내용에 따라 최소 schema1/2/3 writer를 유지한다. 기존1~3 읽기·8MiB/원자적 교체/외부 수정 지문·상대 경로 규칙을 보존한다. 이전 schema에서 새 필드를 숨겨 읽지 않으며 미래5를 거절한다. 프로젝트 native schema 상한80은 변경하지 않는다.

근무 요일·구간·휴일은 공유 달력에서 설정한다. 가용기간 자체가 근무 시간을 생성하지는 않는다. 실제 타임시트/초과근무·자재 입고·비용 최적화와 여러 파일의 통합 날짜 채택은 별도 범위다.
