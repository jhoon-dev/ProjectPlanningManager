# 자재 제약을 포함한 총여유·자유여유·임계

2026-11-17 · MF-01~07. [자재 입고 자동 대기](material-arrival-leveling.md), [실제 자재 원장](actual-materials.md), [공유 통합 실제 자재](shared-material-actuals.md)의 후속이다.

평준화 비교에서 계산하거나 계획/잔여 평준화를 채택하면 자재 입고 시각·재고·소모를 포함한 여유와 임계를 표시한다. 공유 통합 일정에도 적용한다. 현재 배치의 완료일과 자원 반환 순서를 유지하는 범위이며, 원본 날짜·자재 원장을 변경하지 않는다.

- **MF-01 의미:** 총여유는 다른 작업도 현재보다 늦추면서 해당 작업의 시작을 가장 늦출 수 있는 근무분이다. 자유여유는 다른 작업을 현재 날짜에 고정한 최대 지연이다. 달력·관계/시차·고정 날짜·작업 중단·실제 자원 배정률/가용량과 재고가 모두 유효해야 한다. 임계는 인증된 총여유0이다. 완료 실적 작업의 미래 여유는 해당없음이다. 서로 다른 작업의 최후 날짜는 서로 다른 배치일 수 있다.
- **MF-02 자재:** 개시 재고/시각, 계획 입고와 start/finish/uniform 소모를 기존 정확한 milli 정수 누적으로 검사한다. 같은 시각의 입고를 함께 반영하며 서로 다른 자재 재고를 합산하지 않는다. 단일 문서의 자동 대기 옵션을 끈 수동 계획도 현재 재고가 유효하면 계산한다. 입고/재고 시각이 없는 기존 총량 자재는 기존 의미를 유지한다.
- **MF-03 잔여/공유:** 잔여 예측은 상태일의 확인 재고·명시 잔여 소모·미입고 잔량을 사용하고 실제 시작/완료를 고정한다. 공유 일정은 구분된 프로젝트별 재고와 공유 자원·교차 관계를 함께 검사한다. 계획에서 자동 대기를 끈 원본은 통합 배치를 만든 뒤 여유 검산에만 투영하므로 자동 대기를 새로 적용하지 않는다. 실제 자재 원장/잔여 옵션이 없는 예측은 기존 진단대로 거절하며 부족한 입력을 추정하지 않는다.
- **MF-04 탐색/증인:** 자재를 함께 쓰는 작업은 자원 점유가 겹치지 않아도 같은 탐색 묶음에 둔다. 후보마다 선택된 작업과 고정 배경의 재고를 검사하고, 최대 총여유 배치·자유여유 배치·결합 인증을 다시 검산한다. 아직 선택하지 않은 작업의 양수 소모를 제외한 부분 재고 검사는 안전한 필요조건으로만 사용한다. 공수 곡선 때문에 늦은 시작이 더 이른 완료를 만드는 경우도 분 후보를 열거하며 재고 가능성을 이분 탐색하지 않는다. 기존 작업별 재배치 창에서 총여유 배치를 확인할 수 있다.
- **MF-05 화면/출력:** 기존 비교/채택 표·간트/임계·보고서에 같은 값을 전달한다. 작업 표 tooltip·일정 인쇄·증인 창에서 자재 검산을 명시한다. 통합 표와 JSON/XLSX/PDF에 총여유·자유여유·임계를 제공한다. JSON은 선택적 `floatPolicy`와 nullable `freeFloatMinutes`, `critical`을 추가한다. 계산 정책은 `/resource-material-float-v1`, 진단은 `MATERIAL_FLOAT_POLICY`다. 통합 원본 revision/작업공간 generation과 실패 후 무효화를 유지한다.
- **MF-06 저장/재현:** 새 자재 평준화 승인 기준선은 `jobs-adopted-material-leveling-1.0`을 기록한다. 이 엔진을 쓰는 기준선이 현재 문서나 통화/ID 이관 전후 사본에 있을 때만 native **schema84**다. 일반 자재 문서는 기존81/82/83 최소 writer를 유지한다. 이전 승인 엔진1.0~1.8 및 기간별 배정 엔진은 당시의 자재 여유 미산정 결과로 재실행한다. 기준선 입력/결과와 시나리오 입력·복구를 보존한다. 새 영속 필드는 없고 작업공간 형식은 유지한다. 지원 상한84, 미지원 미래85다.
- **MF-07 한도/범위:** 기존 재배치의 작업10,000개·후보 시작250,000개·후보 구간/검사/증인 한도에 더해 재고 검산100,000회·누적 추정 작업량100,000,000을 제한한다. 취소를 전달하며 한도/검산 실패 시 유효한 전진 일정은 유지하고 여유·임계·증인을 일괄 미산정 처리한다. 전역 최적 자원 순서·최소 완료일·구매/비용 최적화·프로젝트 간 자재 풀·여러 원본 파일 날짜 일괄 채택은 별도 범위다.

예를 들어 입고09:02, A/B 각2분 직렬 작업, 독립 완료 작업10분이면 A09:02/B09:04 배치를 유지하면서 A 총여유4분·자유여유0분, B 총/자유여유4분을 계산한다. 반대로 상대 공수 곡선에서 시작09:00→완료09:07, 시작09:01→완료09:05가 되는 작업은09:07 입고 전 소모 때문에 늦출 수 없어 자재 임계가 될 수 있다.

공유 통합은 수치와 계산 정책을 출력한다. 작업별 재배치 날짜 창은 단일 문서에서 제공하며 통합 계산의 내부 ID/시작 기준 작업을 보고서에 노출하지 않는다.
