# 평준화 총여유 근거 탐색

평준화 비교 창의 A/B 결과에서 작업별 총여유의 검증된 재배치를 읽기 전용으로 확인한다. 엔진1.4~1.8의 구조화된 불변 날짜를 사용하며 [계산 계약](leveling-float.md)의 순서 정책·탐색 예산·기준선·schema9~14를 따른다. 현재1.8은 추가 비용 판단과 이동 가능128개 초과와 후보 축소·비단조 필수 부하/연쇄 전파·인증 공유를 지원한다. [효율화 계약](candidate-propagation.md).

## 사용 방법

1. 평준화 비교 결과가 나온 뒤 **A 총여유 근거**를 연다. 저장된 B 시나리오를 비교 중이면 **B 총여유 근거**로 B의 입력과 결과를 확인한다.
2. **총여유를 확인할 작업**에서 증인이 있는 작업을 고른다. 요약의 총여유/자유여유와 표의 현재 날짜/증인 날짜를 비교한다. 선택한 작업 행으로 이동한다.
3. 기본 **선택 작업과 이동한 작업만**에서 해당 배치에서 함께 이동한 작업을 확인한다. 체크를 해제하면 전체 작업과 현재 날짜를 유지하는 작업·완료 실적을 볼 수 있다.
4. 실제 시작/완료는 별도 고정 열이다. 창을 닫아도 원본은 바뀌지 않는다. 비교 조건이나 문서가 변경되면 근거 창이 닫히므로 비교를 다시 계산한다.

## 수용조건

- WITNESS-01: 계산 worker가 성공한 재배치의 작업 ID·시작/완료·잔여 시작을 구조화된 불변 세션 정보로 제공한다. 진단 문자열을 역파싱하거나 모든 작업의 최후 날짜를 조합하지 않는다. 실제로 이동한 작업과 선택 작업만 저장하고 나머지는 현재 날짜로 재구성한다. 실패/취소/미산정에서 부분 증인이 노출되지 않는다.
- WITNESS-02: 비교 창의 A/B 근거 버튼으로 작업을 선택하고 총여유·자유여유와 현재/증인 날짜를 확인한다. 함께 이동한 작업만 보는 기본 필터와 전체 작업 보기를 제공한다. 실제 시작/완료는 별도 고정 값으로 표시한다. 자원 순서 기준과 각 작업의 증인이 서로 다른 배치일 수 있다는 설명을 표시한다. 원본 일정에 적용하는 동작은 추가하지 않는다.
- WITNESS-03: 원본 입력/이름과 같은 ID/revision의 결과를 연결하고 A/B의 서로 다른 입력을 각자 표시한다. 비교 조건 변경·재계산·채택 제출·문서 편집/교체·비교 창 종료 시 열린 근거 창을 닫고 다시 계산하도록 한다. 저장만으로 같은 revision을 가진 결과를 무효화하지 않는다.
- WITNESS-04: 전체 작업 표는 가상 모델로 표시하고 대형 입력을 QTableWidget 셀로 복제하지 않는다. 큰 고정 묶음과0여유·증인 없음·잔여 예측/고정 실적을 검사한다. native 저장에 증인 정보가 들어가지 않고 기존 수치/보고서와 승인 기준선이 유지되는지 검증한다.

## 예시와 한계

A8시간의 월12시~화09시 수동 중단, 같은 자원의 B4시간, 독립 C24시간 사례에서 B의 총여유는9시간, 자유여유는1시간이다. B의 총여유 근거는 A를 수요일09~18시, B를 화요일14~18시로 함께 이동한 실제 가능한 배치다. 화면은 이 차이를 보여 준다. 자유여유는 다른 작업 날짜를 고정한 수치이며 별도의 자유여유 재배치 화면은 이번 범위에 포함하지 않는다.

증인이 없는 전체 구간/실행 창 계산 결과는 근거 버튼을 비활성화하고 이유를 표시한다. 선택 작업이 표에서 숨겨져도 근거 창의 작업 선택으로 확인할 수 있다. 증인의0여유는 미산정과 구분한다. 다른 작업의 최후 날짜나 다른 증인을 한 화면의 배치에 덧붙이지 않는다. 외부 제품 동등성·P6 실제 실행은 별도 검증이다.

함께 이동하는 작업은 **표시한 검증 배치의 이동 목록**이다. 최소 이동 목록이나 반드시 이동해야 하는 작업이라는 뜻은 아니다. 탐색이 선택한 한 증인이므로 총여유와 자유여유가 같아도 동료 이동을 포함할 수 있다.

엔진1.5 이상의 진단/보고서는 큰 증인의 날짜를 최대20개/16,000byte로 미리보기하고 생략 개수를 표시한다. 이 창은 미리보기 문자열을 읽지 않으므로 구조화된 전체 날짜와 작업 선택/필터를 계속 제공한다.

## 검증

[Windows Release 검증 기록](validation/leveling-witness-2026-11-04/README.md)에 전체90/90·독립18종·파서114개·형식149파일, A/B/실적/좁은 창 화면과 준비된1만 행 모델 관측을 보존한다. 엔진1.4의 수치/기준선과 기존 파일 형식은 유지한다.
