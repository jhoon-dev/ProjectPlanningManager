# 이동 가능128개 초과 여유·임계 검증

검증일: 2026-11-04. Windows Release / Qt6.8.3 / MinGW GCC13.1. 전체 CTest **91/91**, **351.73초**, 파서114 seeds(schema1~14), clang-format18.1.8 **151파일**, 독립 reader/비교기 자체시험 **19/19** 통과. 원시 근거는 `ctest.log`, `format-gate.json`, `independent-summary.json`, `verification-summary.json`에 보존한다.

## 계산 범위와 분해의 근거

새 선택 엔진은 `jobs-adopted-leveling-1.5`다. 128개 고정 제한을 제거하고 [LEVEL-FLOAT-16~18](../../leveling-float.md)을 구현했다. 후보마다 성립하지 않는 논리/자원 반환 조건으로 작업을 결합한다. 같은 자원의 후보 수요 포괄 범위가 겹치면 배정률과 무관하게 결합하므로 세 작업의 합산 초과를 쌍별 용량 검사로 누락하지 않는다. 포괄 범위는 실제 후보 구간의 보수적 상위 집합이다. 분해를 더 잘할 가능성은 남아 있지만 실제 결합을 빠뜨려서는 안 된다.

분리된 단위 사이의 논리 조건은 모든 후보 조합에서 성립하며 자원 수요 범위는 겹치지 않는다. 고정 작업과 다른 단위는 현재 날짜로 예약한 상태에서 해당 단위를 탐색한다. 분해되지 않는 큰 단위도 반복형 스택으로 탐색한다. 후보가 적은 동료부터 검사해 불필요한 조합을 만드는 사례를 확인하고, 연결이 많은 작업 우선 순서로 보완했다. 모든 총여유 결과의 전체 프로젝트 자원 부하를 native 실행 모델로 검증한다.

수학적 정책은 `resource-repartition-float-v3`다. 최종 자원 반환 순서를 유지하며 전역 자원 순서 최적화나 임의 선점 분할을 추가하지 않았다. 전체10,000작업·후보250,000·후보 구간2,000,000·판정2,000,000·증인 날짜2,000,000 예산을 유지한다. 한도를 넘으면 현재 날짜/유효 상태를 유지하고 여유·임계만 미산정으로 남긴다.

## 수치와 독립 검산

각 T작업은1근무분·자원100%이며 총여유2분을 갖는다. 조밀한 체인은 자유여유가 마지막만2분, 나머지는0이다. 분리 사례는 각 T작업 뒤 고정 완료 경계 M을 두고3근무분 간격으로 배치하여 모든 T작업의 자유여유도2분이다. 독립 완료일 H와 고정 M의 여유는0이며 임계로 판정한다.

| 이동 가능 작업 | 전체 작업 | 탐색 단위 | 단위 최대 작업 | 증인 |
| ---: | ---: | ---: | ---: | ---: |
| 129 | 130 | 1 | 129 | 129 |
| 512 | 513 | 1 | 512 | 512 |
| 1,000 | 2,001 | 1,000 | 1 | 2,000 |

독립 Python 검증기는4작업/2분 여유의 원시 전수 조합으로 체인15개·독립 창81개 허용 배치를 대조한다. 큰 사례는 순서/완료 상한으로 최대 여유를 유도하고 모든 **2,641개** 증인·**280,785개** 날짜 참조를 재구성해 원본 하한·고정 경계·자원100% 합산·관계·완료일과 작업별 총여유를 검사한다. 메트릭은 반복된 날짜를 `date_records`와 참조 인덱스로 손실 없이 저장하며 보관 사본은 `metrics.json.gz`다. 독립 Python 검증기는 C++ 탐색 구현을 호출하지 않는다.

최종 실행의 논리 일정 계산+파생 여유 단회 관측은129개206.658ms, 512개2,091.7846ms, 분리된1,000개7,296.7521ms다. 직렬 자원 전진 배치·UI/파일 출력과 반복 표본/최악 성능 보장은 포함하지 않는다. 전체 확장 계약은16.01초에 통과했다.

추가 계약은4종 관계/양음 지연의1.4/1.5 수치 일치, 세 작업50%의 단위 결합/실제 합산, 교차 분할 A/B와130개 이동 가능 SS 동료(A660/B540·FF60, 동료TF2/FF0), 129개 잔여 예측에서 실제 시작 고정, 후보250,000 초과의 원자적 미산정·취소·반복 계산을 검사한다. 위 관측은 제한된 fixture이며 모든 대형 프로젝트의 계산 가능/성능 보장이 아니다.

## 보존과 출력

native `selected.ppm`은 schema12이며 기존1.4의129개 제한/미산정 승인 수치와 새1.5 기준선을 함께 저장·재열기·재검산한다. 기존1.0~1.4 재현 경로와 파일 schema9~14 선택 규칙을 유지한다. 새 입력 필드는 없다.

큰 증인의 진단은 최대20개/16,000byte 날짜를 미리보고 생략 개수를 명시한다. 원래 전체 구조화 날짜는 유지한다. 129개 근거 창은129개 작업의 날짜를 표시하며 XLSX/PDF는109개 생략과 전체 근거 창 안내를 표시한다. 독립 openpyxl/pypdf가 일정 수치·출처1.5·32,767자 셀 한도·명시적 미리보기와217쪽 PDF를 다시 판독했다. 화면은 실제1.5 계산 결과이며 준비된 가짜 날짜를 붙인 대형 표 시험이 아니다.
