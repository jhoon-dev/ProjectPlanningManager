# 총여유 근거 탐색 검증

검증일: 2026-11-04. Windows Release / Qt6.8.3 / MinGW GCC13.1. 전체 CTest **90/90**, **349.79초**, 파서114 seeds(schema1~14), clang-format18.1.8 **149파일**, 독립 reader/비교기 자체시험 **18/18** 통과. 전체 회귀·형식·독립 reader 결과는 `verification-summary.json`, `ctest.log`, `format-gate.json`, `independent-summary.json`에 보존한다.

## 동작과 근거

[WITNESS-01~04](../../leveling-witness.md)에 따라 평준화 비교 창의 **A/B 총여유 근거**에서 작업별 현재/검증 날짜·함께 이동한 작업·총여유/자유여유와 고정 실적을 확인한다. 기본 필터는 선택 작업과 이동한 작업이며 전체 작업 보기도 제공한다. 작업 선택 시 해당 행으로 이동한다. 1280px 일반 창과900px 좁은 창에서 표/가로 스크롤·설명·닫기 버튼을 확인했다.

작업 B의 총여유9시간/자유여유1시간 사례를 확인했다. B의 증인은 A를 수요일09~18시, B를 화요일14~18시로 이동한다. 전체 보기에서 독립 C는 현재 날짜를 유지한다. A/B의 작업 이름을 다르게 만들어 각자의 입력을 표시하는지 검사했다. 이름의 `<원문>`은 서식으로 해석하지 않고 그대로 표시한다. `view.json`은 실제 가상 표 모델의 읽기 결과이며 독립 Python 검증기가 날짜·입력 구분·이동 상태를 수기 fixture와 대조한다.

잔여 예측은 A의 실제 시작 월09시와 잔여 시작 월10시를 구분한다. 완료 작업 D의 실제 시작/완료를 고정 열에 표시하고 미래 잔여 시작은 —다. 이 증인은 한 가능한 배치이며 동료 이동이 최소/필수 목록이라는 뜻은 아니다. 총여유와 자유여유가 같아도 탐색에서 선택한 동료 이동을 포함할 수 있다.

## 보존·무효화와 규모

worker는 검증된 ID/시작/완료/잔여 시작을 구조화된 불변 공유 정보로 제공한다. 진단 문장 역파싱이나 작업별 최후 날짜 합성은 하지 않는다. 기존1.3 수치와1.4 수치의 일치, 증인의 실제 자원 부하, 미정 용량에서 부분 증인 차단, 구버전/없는 증인·다른 revision에서 날짜 미표시를 검사한다. 엔진1.4의 수학적 기준과 기존1.0~1.3 기준선 재현은 유지한다.

UI 테스트는 열람만으로 입력/dirty/revision을 바꾸지 않는지 검사한다. 같은 revision의 일반 저장은 창을 유지한다. 입력 편집·비교 조건 변경·재계산·채택 제출·문서 교체·부모 비교 창 종료는 열린 근거 창을 닫는다. 다시 계산하기 전 오래된 결과를 열지 못한다. native 사본의 schema9·checksum과 비영속 증인/인계 정보의 부재도 독립 확인한다. 기존 schema9~14 선택 규칙은 바꾸지 않았다.

1만 행 검사는 이미 검증한3작업 증인에 독립 작업 날짜를 붙인 **표시용 준비 스냅샷**이다. 가상 표의 전체 행 수·끝 행 ID·행 선택을 확인하며 측정은 생성/필터 전환 시간만 포함한다. 1만 작업 자원 평준화·여유 계산이나 반복 표본의 처리 성능 검증은 아니다. 현재 계산 한도는 [기존 계약](../../leveling-float.md)을 따른다.

최종 실행의 준비된1만 행 모델 생성/필터 전환 단회 관측은 **37.6173ms**다. 새 UI 계약 자체는5.47초에 통과했다. 기존 분 단위 oracle과1,514개 증인의 독립 재구성·XLSX/PDF/인쇄·교환 판독도 같은 소스에서 다시 통과했다. 모든 source/test 변경은 전체 회귀 시작 전에 마쳤다.

## 소스와 재현

src C++/헤더+CMake206파일의 SHA256은 `77f47d58032dc2fa4bc5d6fee5ac675fabc45e69f1f64fdb636b79e22079dfd4`다. 빌드 식별값과 대조하고 `source-manifest.txt`·`source-identity.json`에 관련 테스트/스크립트/CI/실행 파일 해시를 보존한다. 비교 창과 증인 전달 외 기존 메뉴·일정 편집은 변경하지 않았다. 이전 검증 폴더는 당시 증거로 보존했다.

```powershell
cmake --build build-forecast --parallel 4
ctest --test-dir build-forecast --output-on-failure
python scripts/verify-leveling-witness.py build-forecast
```

Qt/MinGW DLL과 CMake/CTest의 PATH를 설정한다. CI verifier/artifact 단계와 YAML 구조를 로컬 판독했으며 원격 CI/macOS·새 sanitizer/퍼징·실제 프린터/설치 패키지 검증은 수행하지 않았다. P6는 사용자 확인대로 미설치이며 실제 왕복은 미실행이다. MPXJ reader와 비교기 자체시험을 실제 P6 실행으로 보지 않는다.
