[기능 계약](../../xml-conversion-functions.md) · XCV-01~06. CDec/CSng/CVar의 native 고정점·binary32 최근접 짝수/6자리 반올림·형식/기간 보존·범위/오류/Null과 네 범위·요약/배정 전파·미리보기·교환/보고·schema60/전체 사본을 확인한다.

CSng 생성/경계2058건은 [Python 유리수 검사기](../../../scripts/verify-xml-conversions.py)로 확인한다. 십진 입력을 Fraction으로 만들고 float32 후보와 이웃을 정확한 거리/짝수 기준으로 비교한 뒤 이진 결과를 Fraction으로 소수6자리까지 반올림한다. [.NET 비교](../../../scripts/verify-xml-conversions-dotnet.ps1)는 Invariant Single.Parse의 같은2058건을 비교한다. 최종 값의 전체 VBA/NLS 동등성을 가정하지 않는다. 실행 앱은 Python/.NET을 사용하지 않는다.

직접 식은 절반의 양/음수 정수·최소 native 값·CVar 원문/Boolean/Date·Null·CDec/CSng의 형식 제거와 CVar 경과/추정 기간 보존을 확인한다. native 상한 내부 입력이 Single 반올림으로 범위 밖이 되는 오류도 확인한다. 저장된99/777을 결과나 오류 대신 사용하지 않는다.

현재/기준선/시나리오·환산/ID 이력·복구/읽기 전용·이름 변경·undo/redo, 활성60/이전 태그 거절·비활성44를 확인한다. UI는 예시4개·삽입·비동기 미리보기·저장/undo·취소·표 값과800×650 배치를 확인한다. XML 재계산·XER·XLSX/PDF를 별도 판독한다. 실제 MS Project/P6 실행 검증은 아니다.
