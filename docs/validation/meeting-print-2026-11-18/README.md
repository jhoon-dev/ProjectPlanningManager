# UX-W06 회의용 출력 검증

2026-11-18 · [사용법](../../meeting-print.md) · [기획 우선순위](../../planning/21-weekly-update-ux-review.md).

## 구현 범위

회의용 전체 일정·다음 주 시간축 프리셋을 추가했다. 번호·작업명·현재/기준선 완료·편차·보고 상태를 간트와 묶는다.
회의용 기본 작업 범위는 전체 프로젝트·화면 필터 제외이며, 표시 작업/그 안의 선택으로 바꿀 수 있다.
다음 주는 상태일(없으면 프로젝트 시작일)의 다음 월~일이다. 시간축 밖 작업 행도 유지한다.
범위·상태일·기준선·채택 일정 종류를 창 위에서 확인하고 출력 페이지마다 핵심 상태·전체 결과를 반복한다.
전체 완료일과 보고 범위는 출력 행 수와 별개로 전체 프로젝트 기준임을 명시한다.
기존 상세 열·저장된 페이지 설정, 전체 출처와 최신성·취소·읽기 전용·새 파일 원자 저장 계약을 유지한다.
프리셋은 창 한정이다. 페이지 설정만 문서에 저장하는 기존 계약과 엔진·schema는 바꾸지 않았다.
