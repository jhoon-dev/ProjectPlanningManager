# XML 요약 실제·잔여·기준선 기간

2026-11-15 후속: [외부 XML 기준선](xml-baseline-exchange.md)을 채택했다면 프로젝트 기간은 UID0의 명시 Duration이며 누락 시 미설정이다. WBS/필터 식의 기간은 포함 작업의 날짜 범위를 채택 당시 동결 프로젝트 달력으로 측정한다. XML 원본 WBS의 명시 값은 별도로 보존·출력한다. native 기준선의 아래 기존 의미는 유지한다.

2026-11-15 · XSD-01~06. 작업별 기간을 합산하지 않고 포함된 작업의 날짜 범위를 프로젝트 근무 달력으로 측정한다. 병렬 작업·비근무일·그룹 필터를 반영한다. 기존 작업별 보고 실제 기간과 작업 달력 기반 잔여/동결 기간은 유지한다.

- XSD-01: 프로젝트의 `[Actual Duration]`·`[Remaining Duration]`·`[Baseline Duration]` 및 `[Baseline0 Duration]`~`[Baseline10 Duration]`을 지원한다. 다른 범위에서는 `Project.` 접두사로 전체 프로젝트를 참조한다. 작업 CalculationType=2 식의 같은 참조는 현재 WBS/그룹/필터에 실제 포함된 작업만 요약한다. 자원 자체 기간·배정 자체 기간은 지원하지 않는다.
- XSD-02: 기준선은 동결 시작의 최소~완료의 최대를 **그 승인본의 동결 프로젝트 달력**으로 계산한다. 작업의 중단·개별 달력을 합산/합성하지 않는다. 프로젝트 전체는 동결 전체 작업(현재 삭제된 작업 포함)을, WBS/그룹은 현재 포함된 ID를 사용한다. 기준선에 없는 포함 작업은 미설정이다.
- XSD-03: 잔여 기간은 현재 검증된 상태일 예측의 미완료 작업에 한해 잔여 재개 최소~완료 최대를 현재 프로젝트 달력으로 계산한다. 완료 작업은 범위에서 제외하며 포함 작업이 모두 완료면0이다. 빈 그룹은 미설정이다. 예측 없음/취소/불완전은 미설정, 오래된 결과·충돌·잘못된 행은 오류다. 계획으로 대체하지 않는다.
- XSD-04: 실제 기간은 현재 상태일 이하 최신 정정 보고의 실제 시작 최소~실제 구간 끝 최대다. 완료 작업의 끝은 보고 실제 완료, 진행 중 작업의 끝은 현재 상태일이다. 명시 미시작/실제 기간0은 범위를 늘리지 않으며 모두 명시 미시작이면0이다. 포함 작업 중 미보고는 미설정이다. 보고 실제 기간을 더하거나 실제 시작/기간으로 완료 사실을 추정하지 않는다. 따라서 작업별 보고 실제 기간과 요약의 날짜 범위 측정은 의미가 다르다.
- XSD-05: 기본 프로젝트 근무 달력은 XML 프로젝트 달력 ID가 있으면 그 달력, 없으면 기존 표준 평일/8시간·프로젝트 휴일이다. 기준선은 동결 달력을 사용한다. 정수 마이크로초/소수6자리 근무 분을 보존하고 최대5,000,000분을 넘으면 오류다. 상태일·개별 달력·보고/정정 원장·동결 사본은 변경하지 않는다. 취소·문맥/세대 격리와 worker 계산을 유지한다.
- XSD-06: 프로젝트 기간 바인딩과 작업 요약 기간 식은 조건부 schema74로 저장한다. 새 프로젝트 바인딩은 구버전 태그에서 거절한다. 과거 버전에서 허용했지만 미설정이었던 작업 요약 설정은 계속 읽고 새 요약 의미로 평가하며 다음 저장 시74로 올린다. 활성/비활성의 참조/요약 설정과 전체 이력 사본을 검사한다. 기존 작업별 기간만 사용하는 파일은 기존 최소 writer를 유지한다. 참조 삽입·미리보기·표/보고서·XML 식/정적 값·XER 정적 값과 복구를 연결한다. 실제 Project/P6의 요약 기간 재계산 동등성을 주장하지 않는다.
