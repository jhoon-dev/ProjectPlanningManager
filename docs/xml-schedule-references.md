# XML 계산식의 계산된 일정 참조

2026-11-11 후속: [실적 Actual Start/Finish 참조](xml-actual-references.md)는 상태일 기준 원장 값을 사용한다. 아래의 과거 Actual 제외 표기는 이 지원 범위로 대체한다.

2026-11-11 · XMLS-01~05.

XML 외부 계산식이 스케줄러가 계산한 날짜를 참조한다. 날짜 연산·형식은 [기존 계산식 계약](xml-external-formulas.md)을 따른다.

| 참조 | 사용 범위와 의미 |
|---|---|
| `[Start]`, `[Finish]` | 작업: 해당 작업의 계산된 시작/종료. 프로젝트: 전체 계산 시작/완료 |
| `[Project.Start]`, `[Project.Finish]`, `[Project Finish]` | 네 범위에서 전체 계산 일정. 시작은 작업의 가장 이른 시작, 종료는 스케줄러의 프로젝트 완료 |
| `[Task.Start]`, `[Task.Finish]` | 배정에서 소유 작업의 계산 날짜 |
| `[Project Start]` | 기존의 명시 프로젝트 시작일. 계산된 시작과 구별 |

예: `DateDiff("n",[Start],[Finish])`는 시작과 종료 사이의 달력 분을 계산한다. 점심·야간·휴일도 포함한다. 근무 분이 필요한 계산을 대신하지 않는다. `DateAdd("d",1,[Finish])`는 종료에서 달력 하루 뒤의 날짜다. 기존 `[Duration]`/`[Work]`는 명시 입력을 유지한다.

화면·작업/자원 보기·수식 미리보기·보고서는 활성 계획 또는 상태일 예측을 사용한다. 선택한 평준화 정책은 해당 스케줄러 결과에 포함된다. 완료 실적이 반영된 예측이면 그 결과 날짜를 참조한다. XML/XER 내보내기의 정적 UDF 값은 현재 계획을 사용하고 XML 진단과 보고서 출처에 기준을 표시한다. 외부 제품에서 재계산하면 이 앱의 정책과 달라질 수 있다.

작업의 CalculationType=2 요약 식에서 Start/Finish는 해당 WBS 또는 필터/그룹에 실제 포함된 하위 작업의 최소 시작/최대 종료다. `[Project.Finish]`는 필터와 관계없이 전체 완료다. 빈 그룹은 미설정이다. CalculationType=1은 기존 형식별 집계를 유지한다. 배정의 Task 날짜는 작업 날짜이며 배정 자체 기간을 뜻하지 않는다. 자원/배정의 bare Start/Finish, Resource.Start/Finish, Actual/Early/Late/Baseline 날짜 참조는 실행하지 않는다.

## 평가와 화면

도메인 수식 실행기는 스케줄러를 호출하지 않는다. 계산 계층이 불변 일정 값의 평가 범위를 제공하며, 정확히 같은 입력 객체에서만 유효하다. 계산 중 검증에는 날짜 문맥을 차단하여 수식→일정→검증의 재귀를 피한다. 일정별 메모 키로 native/XML 혼합 참조까지 분리한다. 결과가 없거나 불완전하면 미설정 사유를, 오래된 결과·충돌·잘못된 행이면 오류를 표시한다. 원본 스냅샷으로 대체하지 않는다. 취소는 상위 작업으로 전달한다.

작업 표는 기존 계산 결과를 사용한다. 셀 조회에서 일정을 재계산하지 않는다. 계산 세대/입력이 바뀌면 값 캐시를 폐기하고 선행 변경의 영향을 받은 행도 갱신한다. 수식 설정의 일정 미리보기는 취소 가능한 worker에서 실행하며 변경된 문서/세션이나 이전 미리보기 결과를 적용하지 않는다. 실행 여부·수식 저장·제거·undo·읽기 전용 규칙은 기존 계약을 따른다.

## 보존과 교환

새 참조의 key는 `builtin:start`/`builtin:finish`이며 Task/Project scope를 함께 보존한다. 새 바인딩이 현재·기준선·시나리오·일정 채택 원본/전후·통화/ID 이관 전후 사본에 있으면 조건부 schema45다. 이전 데이터의 최소 writer는 유지한다. schema44 이하에서 새 바인딩을 거절하며 복구도 schema45를 읽는다. 날짜 결과나 실행 문맥은 파일에 새로 저장하지 않는다.

기존 사용자 필드 바인딩은 이름이 새 예약 이름과 같아도 설정 창에서 다시 편집할 때 안정 ID를 유지한다. 새 식에서는 예약 일정 참조가 우선한다. XML 내보내기는 기존 사용자 참조를 출력 슬롯/안전한 필드 이름으로 바꾸고, 일정 참조는 Start/Finish와 범위 접두사로 출력한다. 비활성 식과 원본 값 보존·XML 재가져오기의 재활성화는 기존 계약과 같다.
