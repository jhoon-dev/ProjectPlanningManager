# 평준화 결정 원장 (GAP-06)

2026-11-05 구현 계약. PRD-03/06/08, J-03/06/07/14와 연결한다.

- 채택·교체·해제·입력 변경에 의한 무효화·undo/redo가 현재 평준화 설정을 바꾸면 같은 편집에 결정 한 건을 추가한다. 실패·취소·오래된 worker 결과·변경 없는 요청은 원장을 바꾸지 않는다.
- 각 결정은 안정 ID, 이전 결정 ID, UTC 기록시각, 원본 문서 ID, 변경 전/후 revision, 동작, 편집 사유, 변경 전/후 상태일과 계획/잔여 채택 설정을 보존한다. 이전 설정이 있는 구 파일은 첫 변경부터 기록하며 과거 결정을 추정하지 않는다.
- undo/redo는 설정을 복원하지만 결정을 삭제하지 않고 새 결정을 추가한다. 따라서 원장 변경 후 설정을 되돌려도 저장 필요 상태다. 기존 기준선·실적·원가 불변 원장은 그대로 보존한다.
- 원장이 있으면 native schema 15를 쓴다. schema 1~14 입력과 기존 승인 기준선 엔진은 유지한다. 저장/재열기·사본·복구에서 원장과 원본 출처를 보존한다. 원장 10,000건 한도를 넘는 새 변경은 부분 적용 없이 거절한다.
- 자원 메뉴의 읽기 전용 결정 이력에서 기록 순서·사유·전후 설정·출처를 확인한다. 문서 교체 시 이전 문서 기록을 현재 기록처럼 보여주지 않는다.
- 이 원장은 앱 편집 경계의 불변 이력이다. 승인자 신원 인증이나 파일 변조 방지, 과거 모든 입력/실행 날짜의 완전 재현을 의미하지 않는다. 외부 XML/XER는 원장을 표현하지 못하며 native 원본 사본에 보존한다.

검증은 계획/잔여·직접/worker 편집·자동 무효화·undo/redo·취소/session/읽기 전용·schema/복구·잘못된 원장 거부·읽기 전용 화면을 포함한다. 실제 외부 제품과 다른 OS 검증은 별개다.
