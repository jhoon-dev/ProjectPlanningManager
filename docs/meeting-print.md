# 주간 회의용 일정 출력

2026-11-18 · UX-W06. 파일 메뉴의 일정표·간트 인쇄 또는 Ctrl+P에서 연다.

저장된 페이지 설정이 없는 문서는 **회의용 · 전체 일정**으로 시작한다.
번호·작업명·현재 완료·기준선 완료·완료 편차·상태일 보고를 간트와 함께 출력한다.
완료 편차는 선택 기준선 기본 달력의 근무시간이며 +는 지연, −는 앞당김이다.
기본 달력에서1d=8h이고 휴일은 제외한다. 미정·미보고를0이나0%로 표시하지 않는다.

**회의용 · 다음 주 시간축**은 상태일의 다음 월요일~일요일을 적용한다.
상태일이 없으면 프로젝트 시작일을 기준으로 잡으며, 컴퓨터의 오늘 날짜를 사용하지 않는다.
기간은 시간축과 막대를 제한할 뿐 작업 행을 제거하지 않는다. 완료된 작업이나 다음 주 밖의 작업도 표에 남는다.
기간 밖 막대가 없는 것은 작업 삭제나 미착수를 뜻하지 않는다.

회의용 프리셋의 기본 작업 범위는 **전체 프로젝트 (화면 필터 제외)**다.
필요하면 **현재 표시 작업** 또는 **표시 작업 중 선택**으로 바꾼 뒤 설정 적용을 누른다.
선택이 비어 있으면 전체로 확대하지 않는다. 전체 일정 계산 후 선택한 작업만 출력한다.
머리글의 전체 완료일과 전체 보고 범위는 출력 행 수와 별개로 전체 프로젝트의 결과다.

창 위에서 범위·상태일·선택 기준선·현재 일정 종류·시간축을 확인한다.
선택 기준선 체크는 주 화면에서 선택해 온 기준선을 표시하거나 숨긴다.
각 출력 페이지에도 상태일·기준선·보고 범위·전체 완료일·편차·자원 조정 채택 여부를 반복한다.
상단에서 축약한 긴 이름과 계산 엔진·정책·채택 사유·문서/저장 상태 등 전체 출처는 뒤쪽 페이지에 보존한다.
미리보기의 전체 페이지 수는 출처 페이지까지 포함하며 PDF 저장도 동일한 배치·쪽 수를 사용한다.

**상세 · 화면 표시 열 / 저장된 페이지 설정**은 기존 표시 열·순서·필터와 저장된 용지·기간 설정으로 돌아간다.
기존에 페이지 설정을 저장한 문서는 이 상세 구성으로 시작해 저장된 설정을 유지한다.
프리셋·작업 범위·미리보기 변경은 문서를 수정하거나 자동 저장하지 않는다.
**페이지 설정만 문서에 저장**은 기존 페이지 속성만 명시적으로 저장한다.
회의용 프리셋 이름·핵심 열·전체 프로젝트 범위 선택은 저장 형식을 추가하지 않고 이 창에서만 적용한다.

[기존 인쇄 계약](schedule-printing.md)을 따른다. 인쇄 시작 후 제출한 물리 페이지는 회수할 수 없다.
