# XML 배정·기간별 실제 공수·원가 채택

2026-11-13 후속: [다일 실적 비례 배분 XPR-01~06](xml-multiday-proportional-actuals.md)을 별도 버튼으로 추가했다. 구간 전체 총량 확인과 기준 선택 뒤에만 일별 추정 보고를 채택한다. 아래의 다일 제한은 기본 일별 채택의 계약이며 새 지원 부분은 별도 검토를 따른다. 같은 원본 배정에서 다일 구간과 겹치는 일별 값도 기본 경로에서 우회 채택하지 않는다.

2026-11-13 후속: [표준 실적 XML 출력](xml-standard-actual-export.md)을 추가하면서 ActualCost/Type6의 통화×100 wire 변환을 보정했다. 이전 채택 초안의 표시 금액 해석은 사용하지 않는다. 기존 native 원장은 자동 재환산하지 않는다. 이전 빌드에서 채택한 문서는 원본과 비교해 기간 실적/누계를 명시 정정한다. 같은 원본 재가져오기는 중복 방지로 기존 금액을 바꾸지 않는다. 아래의 표준 쓰기 잔여는 새 지원 범위로 대체한다.

후속: [XAF-01~05](xml-daily-actual-fragments.md)에서 같은 날짜의 겹치지 않는 여러 구간 합산을 제공한다. 아래 내용은 최초 일별 채택의 계약과 당시 검증 범위이며, 하루 내 여러 레코드 제한은 후속 지원 부분으로 대체한다.

2026-11-12 · XAP-01~06. 파일 메뉴의 **XML 배정·기간별 실제 공수·원가 채택…**에서 XML 배정의 일별 실제 값을 현재 native 원장에 반영한다. [작업 날짜/기간 진척 병합](xml-progress-merge.md)과 별도 흐름이다.

- **XAP-01 원본·입력 경계:** Microsoft [TimephasedData Type](https://learn.microsoft.com/en-us/office-project/xml-data-interchange/type-element-multiple-parents?view=project-client-2016)의 배정 실제 공수2·실제 원가6, [Unit](https://learn.microsoft.com/en-us/office-project/xml-data-interchange/unit-element?view=project-client-2016)의 일2를 읽는다. Start/Finish는 분 단위 civil 범위이며 단일 날짜 또는 다음 날 00:00의 종료 경계만 지원한다. 채택 상태일 이후 범위·여러 날·미지원 단위/시간대·중복 날짜/수치·부모 UID 불일치는 거절한다. 배정/작업의 누계 공수·배정 누계 원가에 날짜를 만들지 않는다. 계획/기준선·요약·별도 초과 공수3은 중복 계상하지 않는다. 기본 계획 가져오기는 여전히 실적 미채택이다.
- **XAP-02 정확한 수치·미보고:** 공수는 기존 정수 `%·분` 단위로 변환하며 100u=1자원·분이다. 0.6초=1u처럼 정확히 표현 가능한 소수 기간을 지원하고 반올림하지 않는다. 금액은 명시 CurrencyCode와 native 통화가 같아야 하며 통화 최소 단위를 넘어서는 유효 소수는 거절한다. 표현만 다른 끝자리0은 제거할 수 있다. 명시0과 미보고를 구별한다. 수신에 없는 항목은 해당 날짜의 기존 관측값(미보고 포함)을 보존하며 작업 기간·배정률·계획/급여 단가로 실제 값을 추정하지 않는다. 실제 공수 보고만으로 작업 시작/완료·잔여 계획을 자동 변경하지 않는다.
- **XAP-03 명시 배정·대사:** 모든 행은 미선택, 대상 배정은 미지정으로 시작한다. 원본 배정/작업/자원 UID·날짜·native 작업/자원 쌍·현재/수신 공수·원가와 작업 누계 AC를 비교한다. 노동/장비의 현재 native 배정만 선택할 수 있다. 동일 원본 작업/자원/배정의 연결은 일관돼야 하고 같은 native 배정·날짜에 여러 행을 겹쳐 연결할 수 없다. 이름·순서로 연결을 추측하지 않는다. 현재 문서 상태일을 유지하고 작성자·사유·확인을 요구한다.
- **XAP-04 누계 AC·배분:** XML 일별 원가를 선택한 작업에는 명시 작업 ActualCost 누계가 필요하다. 해당 작업의 기존 날짜별 금액과 선택한 배분을 모두 포함해 native 원장의 모든 역사적 상태일에서 누계≥배분을 검사한다. 누계를 날짜별 금액에 더하지 않고 미배분 잔액을 구별한다. 공수만 선택하면 native 누계 AC(미보고 포함)를 유지한다. 같은 작업의 여러 배정 batch는 같은 누계 값을 각각의 출처와 연결할 수 있으나 누계 보고의 선택 값 하나만 사용한다. 기존 물리 진척도는 유지한다.
- **XAP-05 불변·중복·원자성:** 원본 바이트 SHA-256과 후보를 재파싱 대조하고 source assignment UID·날짜·native 대상·현재 상태일로 이미 채택한 행을 식별한다. 같은 원본의 이미 채택한 행을 다시 선택하면 새 행/revision을 만들지 않고 이후 현장 정정도 되돌리지 않는다. 아직 선택하지 않았던 날짜는 별도 명시 선택으로 채택할 수 있다. 같은 출처 배정의 native 재연결은 거절한다. 다른 원본은 새 명시 검토 대상이다. 기존 보고를 수정/삭제하지 않고 배정·날짜별 마지막 보고를 previousEntryId로 잇는다. 미래 상태일 보고도 보존한다. 여러 배정은 한 native revision으로 검증·반영하며 마지막 행 오류·누계 부족·마감 기간·취소·세션/revision 변경·읽기 전용은 부분 반영하지 않는다.
- **XAP-06 보존·조회:** 기존 PeriodActualEntry/CostEntry와 누계 연결을 재사용한다. 사유에 `[XML-PERIOD sha256=… assignment=…]`·파일명·사용자 사유를 보존하고 날짜·native 작업/자원·종류·통화·이전 보고·UTC를 원장에 기록한다. source assignment UID와 원본 XML로 입력 연결을 검증할 수 있다. 원본 XML 바이트는 native 파일에 내장하지 않으므로 원본 파일을 함께 보관해야 한다. native ID 이관/통화 전환·일반 저장/복구·Usage 실제 공수/원가·기간 실적/누계 대사/정정 이력 XLSX/PDF를 사용한다. 기존 기본 schema11, 지원 상한51을 유지한다. 기존 파일·원본 XML을 자동 덮어쓰지 않고 반영 후 일반 저장한다.

여러 날짜를 포괄하는 버킷의 재배분, 하루 안의 여러 공수/원가 레코드 합산, 날짜 없는 누계의 날짜별 추정, 통화 자동 환산, task/resource 요약의 중복 채택, 표준 실적 XML 재내보내기는 지원하지 않는다. XML 값이 작성 제품에서 계산된 값일 수 있으며 현장 측정 사실을 인증한다는 뜻은 아니다. 실제 MS Project/P6 열기·재계산·재저장은 별도 환경 검증으로 남는다.
