## 편집과 계산

자원 메뉴의 **자재·비용계정·역할 계획**에서 다섯 표를 함께 편집하고 저장한다. 저장은 한 번의 undo/redo로 되돌리며 취소·읽기 전용·열린 이후 원본 revision 변경은 적용하지 않는다. 자재/역할 정의를 바꾼 뒤 해당 참조 탭으로 이동하면 선택 목록을 갱신한다. 참조된 정의를 제거하려면 소모/수요 행도 함께 정리해야 한다.

- 자재는 소모품이다. 수량/재고는 1/1000 단위 정수이고, UI는 소수 3자리까지 허용한다. 빈 재고와 단가는 미정, 0은 확인한 0이다. 전체 계획 소모가 재고를 넘거나 재고가 미정이면 평준화를 차단한다. 지연만으로 재고가 재생되지 않는다. 논리 일정은 계산할 수 있다.
- 자재 원가는 `단가 × quantityMilli / 1000`을 통화 최소 단위의 정수로 half-up 반올림한다. 비용 항목은 작업·이름·비용계정·금액·발생 방식(시작/완료/균등)을 갖는다. 자재와 비용 항목은 기존 고정비·자원비에 각각 한 번만 추가한다. 고정비가 없으면 기존 원가 입력에서 명시적으로 0을 설정해야 전체 예산이 알려진 값이 된다. 빈 금액/단가와 범위 초과 합계는 미정이며, 알려진 0으로 바꾸지 않는다.
- 자재/비용은 계획 원가·일별 원가·기준선 BAC/PV/EV에 연결한다. 균등 원가는 누적 반올림 차이로 배분하여 일별 합계가 총액과 같다. 실제 원가 원장에는 자동으로 지출을 만들지 않는다. 자원별 Usage에는 포함하지 않고 작업 고정비 포함 보기의 비자원 원가에 포함한다.
- 역할은 인력/장비 수요이며 이름을 보고 자동 배정하지 않는다. 구체 자원을 명시적으로 연결하면 같은 작업/자원의 native Assignment 한 건을 관리한다. 수동 배정과 중복 연결하거나 종류가 다른 자원에 연결할 수 없다. 미연결 역할이 있으면 일정은 미완성이다. 같은 연결의 재저장은 기존 기간별 배정 구간을 보존한다. 역할 수요 제거는 관리하던 배정도 제거한다.
- 여유 적은 작업 우선/마감 우선 평준화는 기존 직렬 배정 탐색의 우선순위를 확장한다. 동일 우선순위는 원래 행 순서로 결정한다. 결과의 작업 순서는 원래 순서로 복원한다. 단일 프로젝트에서는 비교 후 기존 채택·결정 원장·undo·기준선·시나리오 절차를 그대로 사용한다. 전역 최적해를 보장하는 비용 최적화가 아니다.

## 통합 일정

작업공간의 **프로젝트 간 링크·통합 일정**에서 서로 다른 프로젝트의 작업을 연결한다. 링크는 안정적인 프로젝트 documentId와 작업 ID의 쌍을 저장한다. 같은 bare 작업 ID가 다른 프로젝트에 있어도 구분한다. FS/SS/FF/SF, ±5,000,000 근무 분 지연을 지원한다. 같은 끝점 쌍의 중복과 같은 프로젝트 링크는 차단한다(로컬 관계 편집 사용).

**링크·옵션 적용**은 작업공간 설정만 바꾼다. 파일 보관은 작업공간 저장을 사용한다. **통합 일정 계산**은 적용 후 모든 프로젝트 snapshot을 동결하여 비동기로 계산한다. 원본 프로젝트의 작업·관계·상태일·채택 설정이나 파일을 변경하지 않는다. 결과는 각 프로젝트 로컬 계산과 통합 날짜, qualified 선행 작업, 통합 여유의 산정 가능 여부, 공유 부하를 제공한다. JSON/XLSX/PDF에 작업공간 generation과 원본 revision을 기록한다. 원본/옵션 변경 후 이전 결과를 지우고 내보내기를 막는다. 계산 취소·오류·stale에는 결과를 확정하지 않는다.

통합 그래프는 native effort 시간축에 프로젝트별 달력·시작 기준·자원·기간 배정을 투영한다. 전체 링크 그래프의 순환과 참조를 먼저 검사한다. 그 후 예측에서는 각 원본이 채택한 진척 정책에 따라 실제 끝점의 역사적 관계를 제외한다. 현재 예측에는 모든 프로젝트의 동일한 상태일이 필요하며, 모두 상태일이 없으면 계획 계산이다. 개별 프로젝트에서 채택한 평준화는 원본에 보존하며 통합 미리보기는 전체 그래프에서 다시 계산한다.

공유 자원 평준화를 선택하면 명시적으로 연결한 자원을 하나의 가용량·달력·날짜 예외로 계산한다. effort 프로젝트의 로컬 자원 달력과 공유 달력이 다르면 차단하여 달력 의미를 임의로 바꾸지 않는다. 이전 duration 프로필의 자원 달력은 원래 실행에서 사용하지 않았으므로 통합 계산의 공유 달력으로 투영한다. 미연결 자원은 프로젝트별 자원으로 남는다. 한 작업의 여러 로컬 자원을 같은 공유 자원으로 연결하면 배정률과 기간 구간을 합산한 하나의 수요로 계산하며, 합산이 native 허용 범위를 넘으면 차단한다. 부하는 독립 프로젝트 일정을 재계산해 합산하지 않고 **통합 계산 날짜**의 점유 구간으로 검증한다. 평준화 후 미정 가용/과부하/잘못된 연결이 남으면 통합 날짜를 확정하지 않는다.

닫힌 프로젝트·삭제된 작업·변경된 참조는 명시적으로 차단한다. 링크가 남은 프로젝트를 작업공간에서 제외하려면 링크를 먼저 제거해야 한다. 링크를 가진 미저장 프로젝트 창을 닫아도 링크/참조를 자동 삭제하지 않으며, 다시 열 수 없으면 링크를 제거한 뒤 닫힌 항목을 제외한다. 계산 상한은 시작 기준 노드 포함 10,000 작업, 100,000 배정, 20,000 달력이다. native 평준화 가용량 상한은 100,000%이고 큰 공유 용량을 임의로 축소하지 않는다.

## 저장과 교환

프로젝트는 이 데이터 또는 새 평준화 우선순위를 사용하면 schema20을 기록한다. 비사용 프로젝트의 기존 최소 schema는 유지한다. PlanInput의 일부로 기준선·시나리오·사본·복구에 보존한다. 작업 복제는 소모·비용·역할 수요 ID와 작업 참조를 재발급하며 삭제는 해당 가변 행을 정리한다. 불변 실적의 삭제 보호는 기존 규칙을 따른다.

작업공간은 링크/통합 옵션이 있으면 schema2, 기본이면 기존 schema1이다. checksum·상대 경로·동시 변경 검사를 유지한다. XER 일괄 패키지는 native 작업공간에 링크/옵션을 보존한다. 선택 범위가 링크의 한쪽만 포함하면 내보내기를 차단한다. 링크를 XER 외부 관계로 투영하지 않으며 변환 명세에 보존 위치를 표시한다. 자재·비용계정·역할은 native 파일 보존 범위이고 P6/MSP 직접 왕복 호환을 주장하지 않는다.
