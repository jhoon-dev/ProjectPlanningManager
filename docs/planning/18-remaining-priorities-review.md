# 미개발 항목 재점검과 다음 증분

**현재 잔여 항목은 [곡선 역산 후 재점검](19-work-contour-remaining-review.md)을 우선한다.** 아래 표는 증분별 판단과 완료 근거를 보존한다. 6번의 FixedWork/FixedUnits 상대 곡선 역산은 [WCI 계약](../work-contour-inverse.md)으로 확장했다.

점검일 2026-11-06. 현재 작업 폴더의 구현·CMake 검사·기능 계약과 [GAP-01~14](16-product-gap-priorities.md), [이전 개발 순서](17-remaining-development.md)를 대조했다. 미커밋 구현도 포함한다. 과거 표의 “후속”을 현재 미구현으로 자동 판정하지 않는다.

## 현재 완료 범위

native 잔여 여유·임계, 분류/객체 필드, Usage·기간 실적, 평준화 채택/결정 원장, 일정표/네트워크 편집·출력, 다중 XER 작업공간/교환, Steps/지원 활동·진척 정책, 자재·비용계정·역할, 읽기 전용 통합 일정/공유 평준화가 구현되어 있다. 조직/EPS/OBS·포트폴리오·협업/감사, 시드 기반 삼각 분포 CPM 위험 분석, JSON batch/CLI도 구현되어 있다. 기능군 전체의 완료를 뜻하지 않으며 각 계약의 제한을 유지한다.

**서버 인증 → 실시간 동기화 → HTTP API → 주기 실행은 미개발 목록에서 제외**한다. 선택 Python/SQLite 서버의 scrypt·만료/철회 세션·ACL, CAS 버전/이벤트 feed/WebSocket/long-poll, native 미리보기/원자 commit·멱등 영수증, 영속 간격/lease·취소/중단 복구가 구현되었다. [계약](../../server/README.md)과 [112개 회귀 및 HTTP23개 증거](../validation/server-collaboration-2026-11-05/README.md)를 따른다. 임의 필드 병합·SSO/MFA·cron·HA까지 지원한다는 의미는 아니다.

## 이전 계획 공수 증분 수용 기준과 결과 (2026-11-05)

- 고정 기간 배정의 일/주(월~일)/월 목표 공수(h)를 작업·자원 달력, 휴일, 수동 중단과 교차해 정확한 정수 공수 구간으로 변환한다.
- 빈칸/범위 초과/근무시간 없음/미지원 조합은 오류다. 0은 수요 없음이며 가용률 초과를 묵시적으로 잘라내지 않는다.
- 변경 없는 곡선과 선택하지 않은 구간·현재 기간 밖 구간을 보존한다. 입력 시 1/100 자원분으로 반올림하고 검산한다.
- 변환은 초안, 문서 적용은 한 undo 단위다. 실적·동결 기록을 보존하고 취소·stale·세션·권한·읽기 전용을 검사한다.
- 독립 civil-minute oracle, 숫자 XLSX/PDF reader, native 저장/복구와 기존 회귀로 확인한다. [검증 기록](../validation/planned-work-2026-11-05/README.md)에 실제 결과를 남긴다.

당시 증분 결과: 전체114/114, Windows 기본 UI·800×600 화면, 형식258파일, 독립 native/목표 JSON·숫자 XLSX/PDF 판독을 통과했다. 로컬 실행 runtime74파일도 준비했다. 이 기록은 계획 공수 변환의 완료 범위다. 2026-11-06의 3~5번 지원 부분은 위 최신 상태와 별도 검증 기록을 따른다.
