# 화면과 사용자 흐름

2026-11-03 [기간 실적 입력/정정](../period-actuals.md): 자원 메뉴 또는 Usage 입력 버튼 → 작업 선택 → 날짜/자원/공수/배분 원가와 기존 포함 누계 입력 → 작성자/사유 → 원자적 제출. 원장은 가상 표로 조회하고 정정 초안을 불러온다. 읽기 전용은 조회만 허용하며 오류/취소/문서 교체는 제출을 반영하지 않는다.

2026-11-03 [시간축 Usage](../timephased-usage.md): 자원 메뉴 → 작업·자원 시간축 Usage → WBS/기준선·시작/끝·일/주/월 선택 → 조회 → 작업/자원 계층과 공수/원가 지표 전환 → XLSX/PDF 출력. 상태일 누적 실제원가는 별도 열에 표시하며 일별 실제 입력은 제공하지 않는다. 선택 WBS 전체를 사용하고 주 화면의 임시 검색/분류 그룹으로 계산 그래프나 조회 범위를 자르지 않는다.

2026-11-02 GAP-03 구현 흐름: **프로젝트 → 사용자 정의 필드 / 작업 코드 사전 → 선택 작업 분류 값**에서 사전과 배정을 편집한다. **보기 → 분류·필터·정렬·열 배치**에서 조건을 설정하고 WBS 탐색 안의 분류 노드를 선택해 표·간트 범위를 바꾼다. **현재 보기 저장 / 저장된 보기 적용·삭제**로 배치를 재사용한다. 읽기 전용은 임시 보기와 조회만 허용한다. [분류·보기 계약](../task-classification.md)의 완료 범위와 이후의 장기 UX 제안을 구분한다.
상태: 화면 상세 PROPOSED. Windows/macOS 설치형은 사용자 확정, C++ + Qt 기본 방향은 사용자 위임에 따른 ADR-008 결정이다. 시각 디자인·세부 Qt 모듈/버전은 미확정.

## 첫 입력
프로젝트명→시작일→기본 근무 주/휴일 확인→작업명 목록 붙여넣기→초안 생성.
기간이 없으면 미산정 상태로 두고 완료일을 확정값처럼 표시하지 않는다. '1일' 입력 시 적용 달력과 시간 환산을 확인할 수 있어야 한다.
쉬운 입력은 고급 계산 규칙을 숨겨 오류를 만드는 방식이 아니다. 기본 정책 요약과 미설정 항목을 항상 확인할 수 있게 한다.

## 주 작업 화면
왼쪽 WBS/프로젝트 탐색, 중앙 작업 표와 간트, 선택 작업의 우측 상세, 하단 계산 진단/변경 영향 패널을 기본안으로 제안한다.
표 열은 이름·기간·시작·완료·선행·자원·진척·편차를 기본으로 하고 사용자 정의 가능하게 한다. 실행 취소·다시 실행과 저장/계산 상태를 분리 표시한다.
간트 드래그는 실제 날짜 변경인지 제약 생성인지 먼저 정책으로 정의하고 변경 미리보기로 설명한다.

## 주요 흐름
1. 계획 작성: WBS 편집→기간/달력→의존관계→계산→순환/충돌 해결→승인.
2. 기준선: 계산 입력·결과 확인→명칭·사유→승인→읽기 전용 스냅샷.
3. 실적 보고: 상태일 선택→실제 날짜·완료 작업량·잔여량 입력→불일치 확인→재예측→기준선 편차.
4. 자원: 자원 사전→가용량→배정→히스토그램 과부하→조정 시나리오→비교→선택 반영.
5. 교환: 파일 형식·버전 선택→매핑 미리보기→지원/손실 목록→확인→가져온 버전과 원본 참조 보존.
6. 협업: 담당자가 실적 제출→검토자 승인/반려→현재 계획에 반영→감사 이력.
7. 복구: 변경 이력 선택→영향 확인→새 버전으로 복구. 과거 기록 삭제와 구분한다.

## 화면 목록과 빈/오류 상태
프로젝트 홈, 일정 편집, 네트워크, 달력, 자원/배정, 기준선 비교, 실적 입력, 원가/성과, 위험/이슈, 포트폴리오, 보고/출력, 교환 센터, 관리/감사.
초기 빈 상태는 입력 예시를 제공하되 가상 데이터를 실제 계획처럼 저장하지 않는다. 미계산·실패·오래된 계산 결과를 구분한다. 권한 부족·동시 편집 충돌·가져오기 손실에 재시도/검토 경로를 제공한다.
키보드 탐색, 대용량 표 가상화, 스크린리더 읽기 순서와 색각 대응을 화면별 수용조건에 포함한다.


파일 기본 흐름은 새로 만들기→프로젝트 입력→저장→닫기/열기, 다른 이름 저장→독립파일, OS간 파일 이동→열기다. 계정·서버 없이 수행하며 FILE-T01~09를 적용한다. SaveAs 문서ID·첨부/외부참조·복구·잠금/동기화충돌 계약은15문서에 있다.

2026-11-03 평준화 비교에서 사유를 입력해 A를 현재 일정으로 채택하고 해제할 수 있다. 저장 A의 입력이 다르면 직접 적용하지 못한다. 채택 중 표/간트에는 평준화와 자원 순서 여유·임계를 표시하고 날짜 드래그를 비활성화한다. 계산 불가 시 여유는 사유와 함께 미산정으로 표시한다. 취소·재열기·읽기 전용은 [채택 계약](../leveling-adoption.md)을 따른다.

2026-11-03 Ctrl+P는 [일정표·간트 페이지 설정/미리보기](../schedule-printing.md)를 연다. 현재 보이는 작업 또는 그 안의 선택 작업, 화면 열과 순서를 고정하고 새 전체 계산의 날짜를 출력한다. 페이지 번호/화면 배율은 미리보기 탐색이며 PDF·프린터는 동일 페이지 모델을 사용한다. 변경/재열기된 문서의 이전 준비 결과는 출력 직전에 차단한다.

2026-11-03 보기 → 네트워크 다이어그램…은 비모달 창으로 표 선택을 따라간다. 그래프 카드 선택으로 전체 직접 선행/후행을 조회하고 더블클릭/중심 이동으로 탐색한다. 명시적인 표·간트 이동은 기존 검색/WBS/분류 필터를 해제한다. 확대/축소·맞춤·라벨·표 범위 갱신과 표시 한도/전체 묶음을 제공한다. [계약](../network-diagram.md)을 따른다.

XER 원본에 PROJECT가 여러 개면 [프로젝트 선택](../xer-project-selection.md)에서 ID/코드/이름을 검색한다. 첫 행은 자동 선택하지 않는다. 외부 선행·후행 건수와 차단 사유를 확인하고 선택 프로젝트의 변환 미리보기로 이동한다. 원본 전체에 비선택 프로젝트도 포함됨을 고지한다. 선택 취소/오래된 세션은 기존 일정과 파일을 보존한다.

추적 → 진척 정책 비교…은 기존 계획/실적을 바꾸지 않는 비모달 비교다. ID/이름·변경 필터와 비활성 관계 전문, 실제 날짜/원본 표 이동·진단·JSON 저장을 제공한다. 원본 표/간트의 현재 일정이 B로 바뀌지 않으며 미계산·충돌은 0으로 표시하지 않는다. [계약](../progress-policy-comparison.md).

추적 → 진척 정책 비교 창 안에서 A/B 채택·교체·해제를 제공한다. 담당자와 사유는 필수이며 비동기 검증 후 최신 문서에 한 번만 적용한다. 읽기 전용·오래된 비교·충돌한 후보는 채택할 수 없다. 채택 여부는 본창 요약과 비교창에 표시한다. [사용/저장 계약](../progress-policy-adoption.md).

진척 정책 채택 후 자원 비교에서 그대로 평준화 계산·채택·시나리오 저장이 가능하다. 비교 요약에 적용한 진척 정책을 표시한다. 정책 변경 메타데이터 입력창은 기존 평준화 해제와 재검토를 알린다. [조합 사용법](../progress-policy-leveling.md).

2026-11-05 자원 메뉴의 **기간별 계획 배정·자원 곡선…**은 배정 선택, 일/주/월 행 생성, 직접 구간/배정률 편집, 집중 곡선, 달력 공수/곡선 미리보기와 원자적 적용을 제공한다. 취소·stale·읽기 전용을 처리하고 기본 배정 창에서는 구간을 보존한다. [화면·편집 계약](../assignment-periods.md).

인쇄 창의 설정 문서 저장·WBS 요약·관계선, 네트워크의 원본 수신 관계 편집·드래그 초안/배치 저장·초기화·벡터 미리보기/PDF/인쇄를 추가했다. [사용 흐름](../print-network-extension.md).
