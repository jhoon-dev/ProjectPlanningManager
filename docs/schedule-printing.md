# 일정표·간트 페이지 설정과 인쇄 (GAP-07)

2026-11-18 UX-W06에서 [주간 회의용 출력 프리셋](meeting-print.md)을 추가했다.
저장된 설정이 없으면 핵심 열·전체 프로젝트로 시작하며, 기존 상세 열과 저장된 페이지 설정도 유지한다.
아래 2026-11-03 기록은 최초 구현 당시의 동작과 검증이다.

2026-11-03 다음 단계 개발 요청의 native 증분이다. 파일 메뉴에서 현재 표시 작업 또는 그 안의 선택 작업을 인쇄한다. 화면의 필터·WBS·정렬·숨긴 행과 추가 열 구성을 캡처하고 원본 번호/작업명은 반복한다. 계산은 전체 프로젝트에서 새로 수행하며 출력 범위로 선행 그래프를 잘라 재계산하지 않는다.

같은 불변 스냅샷과 페이지 배치를 미리보기·PDF·프린터에서 사용한다. A4/A3·방향·여백·글자 크기·표 비율·기간/가로 맞춤 또는 일정 일수별 페이지를 설정한다. 긴 열은 가로로 나누고 원본 번호/작업명을 반복한다. 열 너비는 최소폭이며 마지막 열은 표의 남는 폭을 채운다. 긴 반복 제목은 줄임 표시하고 출처에 전체 제목을 보존한다. 긴 셀은 줄바꿈·행 조각 이어짐으로 보존하며 같은 세로 페이지의 표와 막대 높이를 맞춘다. 기준선·상태일·실제/잔여·임계/평준화 자원 순서 여유와 계산 불가 사유·출처/저장 상태를 구분한다. 화면 간트 viewport나 화면 캡처 이미지를 확대 인쇄하지 않는다.

준비는 취소 가능한 worker에서 수행한다. 문서 ID·session·revision·저장 상태를 준비 결과 반영 및 출력 시작 직전에 검사해 이전 결과의 출력을 차단한다. 출력 시작 후에는 고정된 스냅샷을 사용하며 이미 인쇄된 쪽은 회수하지 못한다. 읽기 전용 출력은 허용한다. PDF는 기존 파일을 덮지 않는 원자적 저장을 사용한다. 프린터 선택 취소는 작업을 제출하지 않는다. 실제 프린터의 용지/출력 영역이 미리보기와 다르면 먼저 설정을 맞추도록 차단하며 인쇄 범위는 미리보기 페이지 번호를 따른다.

출력은 계획 입력이나 파일 schema를 변경하지 않는다. 개인 페이지 설정은 이 대화상자 범위이며 프로젝트 영속 설정은 후속이다. 관계 화살표·WBS 요약 행의 별도 출력과 고급 인쇄 레이아웃 편집기는 이번 범위가 아니다. 실제 프린터와 다른 OS에서 실행하지 않은 검사는 PDF/가상 프린터 검사와 구분해 기록한다.

검증은 다수 열/행·긴 한국어 이름·일정 기간 나눔·기준선/상태일·평준화·실적·필터/선택·취소/재열기·읽기 전용·PDF/가상 프린터의 페이지 일치와 원본 불변을 대상으로 한다. 최종 결과와 실행 한계는 별도 로컬 검증 기록으로 남긴다.

## 사용법과 한도

1. 주 화면의 WBS/분류·검색/필터·정렬과 표시 열을 정한다. 숨긴 작업 행/열은 제외하고 원본 번호·작업명은 항상 반복한다. 선택 범위는 표시 작업 안의 선택만 사용하며 빈 선택을 전체로 확대하지 않는다.
2. Ctrl+P로 창을 연다. 표 글자 8~12pt, A4/A3 가로/세로, 균일 여백 5~30mm, 표 비율과 작업명 줄바꿈 폭을 정한다. 기간 자동은 표시 작업과 선택 기준선의 범위를 사용한다. 수동 기간은 작업 자체를 제거하지 않고 막대/시간축을 해당 구간에 한정한다.
3. 가로 맞춤 또는 1~366일씩 기간을 나누고 설정 적용으로 새 미리보기를 만든다. 작업명/긴 셀의 행 조각은 `원본번호+`로 이어짐을 표시한다. 페이지 번호와 화면 배율은 출력 배치에 영향을 주지 않는다.
4. 새 파일명으로 동일 배치 PDF를 저장하거나 인쇄에서 프린터·페이지 범위와 장치가 제공하는 순서/복사 옵션을 선택한다. PDF 저장은 준비된 전체 페이지를 출력한다. 등록된 프린터가 없어도 PDF 저장은 가능하다. 장치 용지가 다르거나 최소 여백을 침범하면 출력하지 않고 설정 수정을 안내한다.

최대 10,000개 표시 작업·128열·16Mi 문자·1,000,000개 실행 구간, 7,320일의 시간축, 2,000개 고유 페이지와 64MiB PDF를 허용한다. 소프트웨어 복사는 최대 99매/20,000쪽이며 프린터가 직접 복사를 지원하면 해당 드라이버 설정을 사용한다. 한도 초과는 범위를 줄이도록 오류를 표시한다. 활성 일정이 불완전/충돌이면 현재 날짜/막대는 미표시하고 유효 기준선과 입력·진단을 구분한다. 미리보기/출력에는 화면의 오래된 날짜 캐시를 사용하지 않는다.

머리글의 긴 제목/반복 열 제목은 축약할 수 있으나 마지막 출처 페이지에 전체 프로젝트명·열 제목·범위·문서 ID/revision·저장 상태·엔진/정책·기준선·상태일·인쇄 ID·UTC를 보존한다. 가로 페이지마다 같은 세로 행 분할을 사용하며 실제 날짜 구간을 관측 실제공수로 간주하지 않는다.
