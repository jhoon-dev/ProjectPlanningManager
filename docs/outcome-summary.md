# 기준선·예측·자원 조정 결과 비교

2026-11-17 · UX-W05. 주 창의 **결과 비교** 또는 **추적 → 계획 대비 비교**에서 연다.

상단 표는 선택 기준선, 현재 계획, 자원 조정 전 실적 반영 예측, 현재 적용 일정의 완료일을 비교한다.
현재 계획에는 계획 평준화 채택이 포함될 수 있다. 현재 적용 일정은 주 창의 계산과 같은 입력·정책을 사용한다.
실적 반영 여부는 상태일과 현재 채택 종류에 따라 달라지며, 계획 채택은 실적 반영 예측으로 표시하지 않는다.
비교 창의 계산은 문서·주 창 계산 캐시·명시 저장 파일을 변경하지 않는다.

**기준선 대비**는 선택 기준선의 기본 달력 근무시간 차이다. +는 지연, −는 앞당김이다.
일(d)과 시간(h)을 함께 표시하며 d는 해당 기본 달력의 하루 근무량이다. 작업별 달력의 기간 합계나 경과일이 아니다.
**조정 전 대비**도 같은 달력을 사용한다. 기준선이 없으면 이 열은 현재 기본 달력을 사용하고 기준선 대비는 —다.
유효한 전체 완료일이 없으면 완료일과 편차를 —로 표시하며, 미정·충돌을0으로 대체하지 않는다.

상단에는 현재 자원 조정 채택 종류·사유, 선택 상태일, 전체 프로젝트의 보고 범위와 배정 작업 범위를 표시한다.
보고 범위는 선택 상태일까지 한 번 이상 보고한 고유 작업 수이며 미래 보고는 제외한다.
미보고를 미착수/0%로 단정하지 않는다. 자원 과부하는 자원별 과부하 시간의 합계이므로 프로젝트 지연시간과 다르다.
0h라도 배정되지 않은 작업의 자원 가용성을 검증한 것은 아니다. 가용량이 미정이면 미정으로 표시한다.

아래 작업 표에서 행을 선택하면 실제 날짜·실제/잔여 기간·진척·관계·자원 배정 변경을 확인한다.
**자원 후보·부하 비교**는 선택 기준선을 이어 받아 아래 자원 비교를 연다.
**채택·해제 이력**은 기존 결정 원장에서 사유·시각·원본과 무효화 기록을 확인한다.
엔진·revision·전체 진단은 **계산 출처·전체 진단 펼치기**에서 조회한다.

자원 비교의 상단 표는 선택 기준선, A 조정 전, 현재 적용 일정, 검토 후보A와 선택한 저장된B를 분리한다.
후보 계산만으로 현재 일정을 채택하지 않는다. 현재 적용 상태와 후보의 현재 채택 설정 일치 여부를 따로 표시한다.
A/B 입력이 다르면 우선순위만의 효과로 해석하지 않으며 조정 전 대비를 —로 표시한다.
A 입력이 현재 문서와 다르면 기존 채택 검증대로 직접 채택할 수 없다.

- A 조정 전 행 → A 원본 부하
- 현재 적용 일정 행 → 현재 적용 부하
- 검토 후보A 행 → A 평준화 후 부하
- 저장된B 행 → B 평준화 후 부하

각 부하 표에는 날짜·자원 가용량·수요·과부하·연결 작업을 표시한다.
일정 비교 탭은 A 조정 전/후와 B의 작업별 이동·실제 날짜 고정·여유를 확인한다.
후보 채택·해제는 기존 필수 사유·검증·취소·읽기 전용·불변 원장 계약을 따른다.
채택 뒤 요약을 새로 계산하고 비교 창으로 돌아오면 최신 입력을 다시 비교한다.
입력이 바뀐 이전 요약은 오래됨으로 표시하고 다시 계산하기 전까지 채택을 막는다.
