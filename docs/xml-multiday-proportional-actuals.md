# 다일 실적 비례 배분

파일 메뉴의 **XML 배정·기간별 실제 공수·원가 채택… → 다일 구간 비례 배분…**에서 명시 다일 구간을 현재 native 배정에 연결해 날짜별 보고로 기록한다. 기본 가져오기와 기존 일별 채택은 다일 구간을 자동 배분하지 않는다. 현재 상태일, 계획 기간·공수·배정률·단가·진척은 그대로 두고 기존 기간 원장에 정정 보고를 추가한다.

## 입력과 검토

각 구간의 선택과 native 노동/장비 배정 연결, 배분 기준, 작성자·사유를 지정하고 **원본 Value는 구간 전체 총량이며 날짜별 값은 비례 추정임**을 확인해야 미리볼 수 있다. 미리보기에는 날짜별 가중분/합계, 정수 배분량, 기존 값과 반영 값, 누계 AC·전기간 배분·미배분을 표시한다. 설정 변경은 미리보기를 무효화한다. 채택 직전에 원본·현재 문서·미리보기를 다시 계산하고 한 revision으로 반영한다.

지원 원본은 배정의 `TimephasedData Type=2` 공수와 `Type=6` 원가이다. 원본 부모 UID, 분 정밀도의 시작/끝, 양의 범위, 정확한 비음수 수량을 검사한다. `Unit=0/1/2/3/5/8`을 허용하지만 **Value를 확인된 구간 전체 총량으로 한 번만 사용**한다. 일반 MSPDI 자료의 단위당 반복 값을 자동 확장하는 기능이 아니다. 단위당 값인 자료는 전체 총량으로 먼저 준비해야 한다.

공수는 정수 `%·분`(100u=1분), 금액은 통화 최소단위이다. 표준 XML ActualCost/Type6의 wire 값은 표시 통화 금액의100배이며 통화 소수 자릿수와 별개이다. 원가를 선택할 때는 현재 문서와 같은 명시 원본 통화와 작업 누계 ActualCost가 필요하다. 새 누계를 날짜 배분에 다시 더하지 않는다. 수신 공수 또는 원가가 없으면 해당 날짜의 기존 척도를 보존한다. 공수만 선택한 경우 현재 누계의 미정도 보존한다.

## 배분 계약

| 항목 | 규칙 |
|---|---|
| XPR-01 원본 | 원본 XML SHA-256·재파싱·선택 구간·수동 배정 연결을 검증한다. 동일 원본 작업/자원의 연결은 일관돼야 한다. |
| XPR-02 가중치 | 경과분 또는 현재 작업·자원 달력의 공통 근무분을 명시 선택한다. |
| XPR-03 정수 | 각 원본 척도 총량을 최대 나머지법으로 보존하고 날짜별 척도를 합산한다. |
| XPR-04 원장 | 기존 값·누계와 대사하고 전체 마감/유효성 검사를 통과한 날짜별 보고를 한 revision으로 추가한다. |
| XPR-05 재시도 | 동일 출처·선택·기준·가중치·대상·상태일은 중복 없이 유지한다. 변경된 재배분은 거절한다. |
| XPR-06 근거 | 원본 구간 번호·기준·가중치 해시·날짜별 비율/정수 결과와 척도별 추정 기원을 보존하고 검토 기록/감사/표준 XML 영수증에 연결한다. |

경과분은 주말을 포함한 민간 시계 분이다. 근무분은 현재 native 작업과 자원의 달력 교집합이며 작업 중단·휴일·휴게를 반영한다. 배정률·단가·자원 용량 예외는 가중치가 아니다. 근무분 계산은 현재 계획 달력의 지원 구간 내에서만 가능하다. 지원 범위 밖에서는 자동 기준 변경 없이 거절하며 경과분 기준을 별도로 검토할 수 있다.

범위는 `[시작,끝)`이다. 끝이 자정이면 그 날짜는 포함하지 않는다. 전체일 버킷은 현재 상태일 날짜까지 허용하고, 시각 구간은 끝이 상태일 시각 이하여야 한다. 미래 날짜를 잘라 총량을 현재 날짜에 몰아넣지 않는다. 가중분0인 날짜는 생략하며 기존 주말 실적을0으로 덮어쓰지 않는다. 전체 가중분0은 거절한다. 양의 가중분에서 정수 배분이0이 되면 알려진 추정0으로 기록한다.

각 구간/척도에 대해 `총량×날짜가중분÷전체가중분`의 정수 부분을 먼저 취하고, 남은 최소단위를 소수 나머지가 큰 날짜부터 배분한다. 동률은 날짜 오름차순이다. 부동소수점으로 수량을 반올림하지 않는다. 원본 Type2/6 최대10000개, 한 구간 최대366개 날짜, 한 번의 선택 최대1000개 합산 날짜 버킷(공수/원가 별도 계산), 원본 배정당 최대32구간, 최종 native 최대1000행을 지원한다. 같은 원본 배정의 오류 구간, 선택 구간과 겹치는 같은 종류의 구간(미선택 포함), 중복 연결, 수량 합계 초과는 거절한다.

## 이력과 추정 기원

원장 사유의 `[XML-PRORATA …]`에는 원본 SHA-256·배정 UID·기준·가중치 해시·선택 구간과 날짜별 `원본구간w/c=가중분/합계:배분량`을 기록한다. 일별 기간 보고와 연결 누계 보고가 같은 사유를 보존한다. 저장 구조를 추가하지 않으며 기존 schema11부터 필요한 최소 writer를 사용한다. 기존 문서의 다른 기능에 따른 schema와 지원 상한51은 유지한다.

동일 배분을 다시 채택하면 후속 수동 정정도 유지한다. 같은 원본 배정·상태일에 선택 구간/기준/가중치/대상을 바꾼 재배분은 자동으로 덮어쓰지 않고 거절한다. 새 상태일·새 원본 또는 명시적인 수동 정정을 검토한다. 원본 그룹은 native ID 이관 뒤에도 연결된다. 계획·전체 기존 원장·미래 보고·원본 파일은 삭제하지 않는다. 오래된 문서, 읽기 전용, 취소, 마감 기간을 검사하고 기존 저장·복구를 사용한다.

`비례 배분 실적 근거` 감사 표와 Usage 안내는 추정값이 섞인 현재 선택을 구분한다. 후속 정정에서 공수만 바꾸고 원가를 그대로 두면 원가의 배분 기원을 원래 보고 ID로 유지한다. 동일 수량을 이어받은 척도는 보수적으로 추정 기원을 유지하며, 변경된 척도는 수동 보고 기원으로 처리한다. 조회 상태일보다 미래인 보고를 기원으로 이어받지 않는다.

선택적인 **검토 기록을 새 폴더에 저장**은 채택 전 `source.ppm`, `original.xml`, `allocation.json`을 생성한다. JSON에는 native 입력/파일 해시, 모든 가중분/나머지/배분량·기존/반영 값·누계 대사와 제출 사유를 남긴다. 기존 폴더를 덮어쓰지 않고 임시 폴더에서 저장/읽기 검증 후 게시한다. 이 기록 저장만으로 현재 문서에 채택하지 않는다.

표준 실적 XML에도 현재 날짜별 수량을 출력하며 `conversion.json`에 척도별 추정 여부·원래 배분 보고 ID/사유를 추가한다. **일반 XML 단독 재수입으로 추정/측정 구분을 복원할 수 없다.** 원래 이력은 native 사본과 영수증을 함께 보관해야 한다. 제품 간 계산 동등성·실제 MS Project/P6 왕복, 시간대/초 단위 구간과 자동 단위당 총량 해석은 이 범위 밖이다.
