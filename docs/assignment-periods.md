# 기간별 계획 배정과 자원 곡선

2026-11-06 [FixedWork/FixedUnits 역산](work-contour-inverse.md)으로 지원 유형을 확장했다. 아래 고정 기간만 지원/공수 역산 불가 표기는 최초 schema17 계약의 범위다. 새 조합은 schema24와 별도 엔진을 사용하며 과거 고정 기간의 실행·잔여 의미는 유지한다.

자원 → **기간별 계획 배정·자원 곡선…**에서 작업·자원 배정을 선택한다. 기간이 확정된 고정 기간 작업을 지원한다. 100%는 자원 1단위다. 기본 배정률은 기존 자원 배정 창에서 변경한다.

## 입력과 곡선

구간은 작업 시작 이후의 **작업 달력 근무분** `[fromMinute, toMinute)`이다. 점심·주말·휴일·수동 중단은 위치를 소비하지 않는다. 구간 밖은 기본 배정률, 명시한 0%는 수요 없음이다. 직접 구간을 추가·삭제하거나 일·주(월~일)·월 경계에서 행을 나누고 배정률을 편집한다. 혼합률은 평균으로 바꾸지 않고 별도 행으로 유지한다. 날짜는 현재 논리 계획의 작업 달력에 투영해 표시한다.

앞쪽·뒤쪽·중앙 집중 곡선은 편집 가능한 정수 배정률 구간을 생성한다. 최대 10개 가중 구간과 정수 나머지 보정을 사용해 작업 달력의 면적을 `기본 배정률 × 기간`과 정확히 일치시킨다. 곡선 이름은 저장하지 않는다. 생성 후 직접 수정한 구간이 유일한 원본이다. 균등은 대체 구간을 모두 제거한다. 자원 달력과의 교집합은 별도로 적용되므로 실제 계획 공수는 명목 면적보다 작을 수 있다. 화면에 교집합을 반영한 공수를 표시한다.

생성은 창 안의 초안을 바꾸고 **문서에 적용**으로 한 번에 반영한다. 다른 배정 선택·저장된 값 불러오기는 현재 초안을 버린다. 계산 취소·창 닫기·다른 문서/같은 문서 재열기·revision 변경은 오래된 결과의 적용을 막는다. 읽기 전용에서는 조회와 미리보기를 지원한다. 일반 자원 배정 창은 기존 구간을 보존하고 빈 구간의 기본률만 바꾼다. 배정 해제는 그 배정의 구간도 제거한다.

최초 대체 구간 적용 시 계획의 계산 프로필을 `native-effort-split-v1`로 승격해 공통 실행 모델을 사용한다. 승격과 구간 입력은 같은 undo 단위이며, 기준선/시나리오의 원래 프로필과 엔진은 보존한다. 구간을 균등으로 되돌리는 작업은 현재 프로필을 자동 강등하지 않는다.

## 기간·달력·실적

작업 이동·평준화 시 시작 기준 위치를 따라 곡선을 재생한다. 기간을 줄이면 밖의 구간을 보존하고 계산에서 잘라낸다. 다시 늘리면 보존 구간이 활성화되고 그 밖에는 기본률을 적용한다. 구간은 기간보다 길게 저장할 수 있다. 화면은 현재 기간 밖 구간을 표시한다. 기간 미정·0·고정 공수/고정 단위·공수 역산과의 조합은 거절한다. 먼저 균등으로 되돌린 후 작업 유형/공수 입력을 바꾼다.

잔여 예측은 원래 계획 기간 `D`, 현재 잔여 기간 `R`에 대해 `max(0, D−R)` 위치부터 곡선을 재생한다. `R>D`이면 0에서 시작하며 저장된 대체 구간이 없는 부분은 기본률이다. 잔여 실행이 늘어나면 현재 계획 기간 밖에 보존한 구간도 해당 위치에서 재생한다. 이는 **잔여 배정 정책**이며 실제 공수 추정이 아니다. 실제 시작/완료·진척·실제공수/원가 정정 원장은 변경하지 않는다. 완료 작업에는 미래 수요가 없다.

## 계산과 출력

작업·자원 달력 교집합을 구간 경계에서 나누는 공통 실행 모델을 사용한다. 계획/잔여 Usage, 순간 최대 부하, 공수, 날짜별 유효 단가 원가, 공유 자원 수요, 평준화 후보를 같은 구간으로 산정한다. 고정 기간 작업의 날짜는 곡선만 변경해도 유지된다. 수동 편집은 총공수를 보존하지 않는다.

평준화 여유는 일정 배정률의 전체 작업 봉투를 사용하지 않고 실제 곡선으로 후보를 검증하는 재배치 경로를 사용한다. 기존 후보/탐색 한도를 넘으면 여유 미산정 사유를 표시한다. 계획 엔진 `jobs-effort-periods-1.0`, 채택 계획 엔진 `jobs-adopted-periods-1.0`, 평준화 정책 `serial-effort-periods-v1`은 구간 없는 과거 엔진과 구분한다. 구간 있는 입력을 과거 엔진으로 재현하는 요청은 거절한다. 과거 파일/엔진 재현 경로는 유지한다. 새 평준화 정책은 정률 공수 입력도 퇴화 곡선으로 허용하므로 현재 곡선을 제거해도 과거 결정 원장의 메타데이터 검증을 유지한다.

자원 보고서의 **기간별 계획 배정 정의**에는 작업/자원 ID·이름·시작/끝 근무분·정수 배정률을 기록한다. XLSX 배정률은 수치/백분율 서식이다. Usage는 일·주·월 적분 결과다. 기준선 비교에는 구간 정의 변경을 표시한다. XML/XER에는 기본 배정률만 투영하고 기간별 곡선의 미지원 손실을 명시하며 native `source.ppm`에 전체 입력을 보존한다.

## 저장과 한도

Assignment의 선택 속성 `periods` 배열에 `{fromMinute, toMinute, units}`를 저장한다. 정렬·비중복, 근무분 0~5,000,000, 배정률 0~100,000%, 배정당 1,024개·계획당 100,000개까지다. 기본률은 기존처럼 1~100,000%다. 겹침·음수·소수·잘못된 타입·알 수 없는 속성·미지원 작업 조합을 거절한다.

현재/어느 기준선/시나리오에 구간이 있거나 새 평준화 정책이 선택/시나리오/결정 원장에 남아 있으면 조건부 **schema17**을 사용한다. 곡선 제거 후에도 과거 정책 이력을 낮은 schema로 저장하지 않는다. 없으면 기존 writer 선택을 유지한다. schema1~17 읽기와 recovery projectSchema17을 지원한다. schema16 이하는 periods를 허용하지 않는다. 기준선/시나리오는 구간 전체를 동결하고 엔진을 재현한다. 편집은 undo/redo·dirty·revision·평준화 자동 무효화/결정 원장을 따른다.
