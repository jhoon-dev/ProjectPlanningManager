# 진척 정책 비교 미리보기 (GAP-10 첫 증분)

2026-11-03 다음 단계 요청. 원본 일정에 채택하기 전에 현재 native 잔여 논리 유지와 진행 중 작업의 수신 관계 무시를 같은 실적 snapshot에서 비교한다. P6 미설치로 실제 P6 검증은 미실행이다. 제품 동등성·P6 Actual Dates·Steps/LOE 구현으로 확대하지 않는다.

## 계산 계약

- 원본 전체 계획을 먼저 검증한다. 순환/누락/미정 기간 등 기존 계획 계산이 유효하지 않으면 관계를 무시하여 오류를 숨기지 않는다. 상태일이 필요하며 현재 채택한 계획/잔여 평준화가 있으면 비교를 차단한다.
- A는 명시적 정책 선택을 제거한 기본 retained-remaining 결과다. 채택 상태에 관계없이 같은 A/B 정의로 비교한다. B는 계산 전용 복사본에서 상태일 기준 실제 시작이 있고 실제 완료가 없는 작업의 모든 수신 FS/SS/FF/SF 관계와 지연을 비활성화한 native what-if 결과다. 비활성 관계를 목록/출력에 빠짐없이 기록하며 원본 선행 관계는 변경하지 않는다. 진행 중이 아닌 후행의 관계는 유지한다.
- 실제 날짜·잔여 기간/공수·달력/배정·수동 중단·유효 제약은 양쪽에서 동일하다. 미완료 시작 관계는 잔여 재개, 고정 실제 시작을 출발하는 SS/SF는 기존 native 의미다. 완료 실적의 미래 여유는 해당 없음이다. 무시한 관계는 B의 전진/후진/자유여유/driving 네트워크 모두에서 비활성이다.
- B의 계획 참조는 관계를 무시하기 전 원본 계획이다. 순서 위반 실적 진단도 원본 A의 진단을 보존한다. B는 native-progress-override-preview-v1로 식별하며 기존 retained 진단 문구를 B에 그대로 표시하지 않는다. A/B 중 충돌한 결과의 날짜/여유를 정상 값으로 확정하지 않는다.
- 표시 편차는 프로젝트 기본 달력의 근무분이며 원시 날짜도 함께 제공한다. 작업별 여유는 각 작업의 기존 native 달력 의미다. 프로젝트 완료·작업 잔여 시작/완료·총/자유여유·임계/변경 작업과 비활성 관계를 비교한다. 기준선·실적/원가 원장·schema·undo 이력·표/간트의 현재 계산은 바꾸지 않는다.

## 화면·세션

추적 → 진척 정책 비교…의 비모달 창에서 새 전체 계산/취소, ID/이름 검색·변경 작업 필터, 관계 목록·진단과 원본 표 이동을 제공한다. 가상 표 모델로 전체 행을 조회한다. 결과 내보내기는 ID/revision/session에 묶인 JSON 비교 기록이다. 편집/undo/재열기 시 이전 결과와 내보내기를 무효화하며 파일 선택 중 변경도 차단한다. 읽기 전용 탐색은 허용한다. [채택·저장 증분](progress-policy-adoption.md)에서는 담당자·사유를 입력해 A/B를 현재 예측에 적용할 수 있다. 비교 실행과 JSON 저장만으로는 채택하지 않는다. 일반 Usage의 잔여 공수/원가·예측 보고서·일정 인쇄에 적용하며 계획 예산과 기준선 EVM은 보존한다.

## P6 확인 경계

Oracle [Schedule Options](https://docs.oracle.com/cd/G48902_01/client_help/en_US/general_tab_-_schedule_options_dialog_box.htm)는 진척 활동의 Retained Logic/Progress Override/Actual Dates와 별도 lag/float 옵션을 설명한다. 이 첫 증분의 B는 위의 명시적인 native 비활성 관계 정책이며 P6와 모든 제약/진척 조합에서 같다는 주장이 아니다. Actual Dates의 후진/음수 여유 의미는 별도 계약/실행 사례가 필요하다.

P6 설치/등록/실행 창을 찾지 못했고 사용자가 미설치를 확인했다. 실제 실행으로 표시하지 않는다. 별도 계획 XER 왕복 검증 자료를 생성하며, 진행 실적은 현재 XER 교환에 실리지 않으므로 P6 진척 정책 시험에서는 실제/잔여를 수동 입력하는 절차를 구분한다. MPXJ/TSV 검사도 실제 P6 실행을 대신하지 않는다.

## 로컬 검증

[Windows Release 전체 CTest 81개·독립 출력/XER 검사·수기 날짜/여유·화면·1천/1만 관측](validation/progress-policy-2026-11-03/README.md)을 통과했다. Save As를 포함한 ID/revision/session 변경과 취소·파일 선택 보호를 확인했다. 실제 P6는 미설치로 미실행이며 준비 파일·비교기 자체시험은 별도다.

평준화 채택 상태에서도 A/B 비교가 가능하며 비교 값은 평준화 전 논리 예측이다. 정책을 채택/해제하면 기존 평준화를 함께 해제하고 새 정책으로 재검토한다. [조합 계약](progress-policy-leveling.md).
