# 주간 갱신의 열 보기·자원 메뉴·일정 탐색

2026-11-18 · UX-W07.

작업 표 위 **열 보기**에서 일정 핵심, 주간 편차·보고, 자원 확인을 선택한다.
일정 핵심은 기간·선행·시작·완료, 자원 확인은 기간·완료·자원·임계/상태를 모아 보여 준다.
주간 편차·보고는 현재 완료·선택 기준선 완료·완료 편차·상태일 보고를 나란히 표시한다.
편차는 기준선 기본 달력의 근무일/시간이며 +는 지연, −는 앞당김이다.
유효한 현재 일정이나 기준선이 없으면 —로 표시한다. 미보고는 미정이며0%가 아니다.
보고 있음·미착수 보고·완료 보고는 선택 상태일까지의 기존 실적을 조회한다.

주간 열3개는 조회 전용이다. 기존 작업·사용자 필드·코드의 번호와 편집 기능은 유지한다.
**전체·직접 배치**로 돌아오면 프리셋을 적용하기 전 열 순서·폭·숨김을 복원한다.
분류 설정이나 저장된 보기를 명시적으로 적용하면 그 열 배치를 사용한다.
주간 조회 열은 창 한정이며 기존 저장된 보기나 상세 인쇄의 열 목록에는 넣지 않는다.
회의용 표를 출력할 때는 [회의용 출력 프리셋](meeting-print.md)을 사용한다.
필드 구조가 바뀌어 이전 열 상태를 복원할 수 없으면 현재 필드의 기본 배치를 사용한다.

본문 안내에서 표시 작업 수·선택 작업·전체 계산/자원 비교 범위와 상태일을 확인한다.
검색·WBS·필터는 표와 간트 보기를 제한한다. 일정 계산과 자원 후보 비교는 전체 프로젝트에서 수행한다.
전체 프로젝트 완료일과 간트에 표시된 작업의 가장 늦은 완료일을 구분한다.
표시 완료일이 시간축 화면 밖이면 안내와 **표시 완료일 보기**로 이동할 수 있다.
이 명령은 가로 시간축만 이동하고 선택·필터를 유지한다. **전체 맞춤**은 기존 시간축 전체를 맞춘다.
**선택 보기** Ctrl+Shift+J와 **전체 맞춤** Ctrl+Shift+F 경로는 유지한다.
작은 높이의 간소 화면에서는 안내 본문을 접고 표시 작업 수의 툴팁으로 전체 안내를 제공한다.

자원 메뉴는 다음 업무로 나뉜다.

- 주간 자원 검토: 등록·가용량, 선택 작업 배정, 현재 부하·잔여 가용량, 후보 비교, 결정 이력.
- 기간별 공수·실적: 날짜별 잔여 공수, Usage, 기간별 실적/원가 입력·정정.
- 자재·역할: 자재/비용계정/역할 계획과 실제·계획 재고.
- 고급 설정·곡선: 생산성·외부 곡선, 자원 보기, 기간별 배정, 활동 확장, 사용자 필드.

메뉴 이동은 기존 명령과 읽기 전용·검증 계약을 바꾸지 않는다.
열 보기·필터·시간축 이동만으로 프로젝트를 수정하거나 자동 저장하지 않는다.

[자동 검사·실제 화면 검증](validation/workspace-navigation-2026-11-18/README.md).

## 간트 범례와 상태

배율 옆 **간트 범례**에서 채움·굵은 임계 테두리·주황 기준선 지연 표시·기준선 막대·선택 행 강조를 확인한다.
미보고 작업은 회색 빗금과 텍스트로 구분하며 착수 여부를 추정하지 않는다. 보고 상태와 지연 표시는 독립적이다.
주황 표시는 선택 기준선 작업 달력의 근무분 편차가 양수인 경우에만 표시한다.
기준선 없음·기준선에 없는 작업·비교 불가는 지연 미정이며 막대 툴팁에서 비교 기준을 확인한다.
선택·WBS/검색 필터·배율·스크롤은 보고·기준선·계산 입력을 바꾸지 않는다. [전체 의미](wbs-gantt.md).
